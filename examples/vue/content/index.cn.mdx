Fumapress 把 `content/` 里的 Markdown 文件变成文档站。这个站点运行在 **Vue** 上，用 [Vue Router](https://router.vuejs.org) 导航，用 [Nitro](https://nitro.build) 作为服务器。

## 功能

<Cards>
  <Card title="Markdown 与 MDX" href="/cn/guide/markdown">
    提示框、标签页、步骤和代码高亮。
  </Card>
  <Card title="插件" href="/cn/guide/plugins">
    用带钩子的对象添加路由、中间件和 head 标签。
  </Card>
</Cards>

## 多语言

`index.cn.mdx` 是 `index.mdx` 的中文版本。没有中文版本的页面会显示英文页面。
