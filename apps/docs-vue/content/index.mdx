`@fumapress/vue` turns the Markdown files of a folder into a docs site. It is a Vite plugin: Nitro prerenders the pages and serves the rest, and the app navigates between them without loading a new document.

## What a Site Gets

Add the plugin to `vite.config.ts` and write pages under `content/`. Without other configuration, the site has:

- A docs layout with a sidebar built from your files, a table of contents, and a light and dark theme.
- Markdown and MDX with callouts, highlighted code blocks, tabs, steps and components like `Cards` and `TypeTable`.
- Search in the browser, from an index generated at build time, so it works on a static host.
- `/sitemap.xml`, `/robots.txt`, `/llms.txt` and `/llms-full.txt`.
- Pages prerendered to HTML at build time, with client-side navigation after the first load.

For more, a site adds `press.config.ts` (site name, links, languages, content sources), a theme module (icons, components, layouts), Vue pages under `src/pages`, and plugins with their own routes.

## Fumapress and Fumadocs

`@fumapress/vue` is Fumapress for Vue. Its config and plugins have the shape of [Fumapress](https://press.fumadocs.dev) on React: the same `createPress()` chain, and plugin hooks with the same names and signatures.

The UI is a port of [Fumadocs UI](https://fumadocs.dev) to Vue, with the same markup and Tailwind classes. The package bundles the parts of Fumadocs it uses, so a site installs neither Fumadocs nor React.

### Differences

- The component of each page type is in [`views`](/theme#page-components) of the theme, not in `ui.renderPage` of the config, since it also runs in the browser.
- A view returns props, and the theme names its component: a component can't be sent from the server.
- A theme names the default theme in `extends` to build on it.
- The compile options of Markdown are global, in the Vite plugin, and the frontmatter of a collection is validated when the server starts.
- The [layout](/ui#choosing-a-layout) is an import in the theme, where Fumapress passes `layout` to `renderDefault`.
- `.views()` exists, so a site adds pages of its own without a plugin.
