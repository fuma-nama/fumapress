title: Internationalization
description: Serve your docs in several languages, each with its own pages, URLs and UI texts.

---

Define your languages with `defineI18n()`, and pass them to `createPress()` with the `i18n` option:

```ts title="press.config.ts"
import { createPress } from "@fumapress/vue/config";
import { content } from "@fumapress/vue/content";
import { defineI18n } from "@fumapress/vue/i18n";

const i18n = defineI18n({
  languages: ["en", "cn"],
  defaultLanguage: "en",
  hideLocale: "default-locale",
});

export default createPress(content, { i18n });
```

Each language has its own pages, page tree, URLs and search index. The layouts show a language switch. The languages are in the types of the site, so `this.localizePath("fr", "/")` is a type error.

## Translating Pages

A translated page sits next to the original, with the language before the extension:

```
content/
├── index.mdx
├── index.cn.mdx
└── guide/
    ├── meta.json
    ├── meta.cn.json
    ├── install.mdx
    └── install.cn.mdx
```

`meta.cn.json` translates the `title` of the folder and its order of pages. Files without a language, like `install.mdx`, are in the default language.

To use a folder per language instead, like `cn/guide/install.mdx`, set `parser: "dir"` in `defineI18n()`.

### Fallback Language

A page without a translation shows the page of the default language, at the URL of its own language: `/cn/guide/english-only` shows the English page. Set `fallbackLanguage` to another language to fall back to it, or to `null` for none: the page then doesn't exist in that language, and its URL is a 404.

## URLs

The language is the first segment of the URL. `hideLocale` sets which languages have it:

- `"never"`, the default: every language has its prefix, like `/en/guide/install` and `/cn/guide/install`. A URL without a prefix, like `/guide/install`, redirects to the page in the default language on a server. A static host has the redirect of `/` only.
- `"default-locale"`: the default language has no prefix, like `/guide/install`, while others have one, like `/cn/guide/install`. On a server, a URL with the prefix of the default language, like `/en/guide/install`, redirects to the URL without it.

Fumapress tells the languages apart by their prefix, so `hideLocale: "always"` fails with an error.

### Links in Translated Pages

A link in a page leads to the URL as it is written: the language of the page isn't added to it. In a translated page, write the prefix of its language:

```md title="content/guide/index.cn.mdx"
[安装](/cn/guide/install)
```

## UI Texts

`ui.translations` translates the texts of the UI. `i18n.translations()` creates the translations of your languages, `.extend(uiTranslations())` adds the keys of the UI, and `.add()` gives the texts by language. A key is the English text followed by its note in parentheses, which tells apart uses of the same text:

```ts title="press.config.ts"
import { uiTranslations } from "@fumapress/vue/i18n";

export default createPress(content, { i18n }).config({
  ui: {
    translations: i18n
      .translations()
      .extend(uiTranslations())
      .add({
        en: { displayName: "English" },
        cn: {
          displayName: "中文",
          "Search(search trigger)": "搜索",
          "Search(search dialog)": "搜索",
          "On this page(table of contents)": "本页内容",
          "Edit on GitHub(edit page)": "在 GitHub 上编辑",
        },
      }),
  },
});
```

`displayName` is the name of the language in the language switch. Without it, the switch shows the language code.

The keys and the languages are typed: a key that isn't in the list, or a language that the site doesn't have, is a type error. The full list of keys is in `node_modules/@fumapress/vue/ui/.translations/keys.json`.

A site without languages translates its UI with `defineTranslations()`, whose `.add()` takes the texts directly:

```ts title="press.config.ts"
import { defineTranslations, uiTranslations } from "@fumapress/vue/i18n";

export default createPress(content).config({
  ui: {
    translations: defineTranslations()
      .extend(uiTranslations())
      .add({ "On this page(table of contents)": "Contents" }),
  },
});
```

## Links per Language

`ui.layoutProps` can be a function of the language, to translate the links of the navbar. `this.localizePath()` gives a path in a language, with its prefix:

```ts title="press.config.ts"
export default createPress(content, { i18n }).config({
  ui: {
    layoutProps({ lang }) {
      return {
        links: [
          { text: lang === "cn" ? "版本" : "Releases", url: this.localizePath(lang, "/releases") },
        ],
      };
    },
  },
});
```

With `parser: "dir"`, the folder of a language is the first one. To also put a collection under a URL prefix, give `toSource` the languages, so the prefix comes after that folder:

```ts
collections.docs!.toSource({ baseDir: "docs", i18n });
```

## Plugins

The default plugins and your views follow the languages of the site:

- Search has an index per language, and the dialog searches the language of the page.
- `llms.txt` and `llms-full.txt` exist per language: at the root of the site for the default language, and at the prefix of the others, like `/cn/llms.txt`.
- The sitemap lists the translations of each page, and each page links to its translations with `hreflang` alternate links. The translations of a page are the pages of other languages at the same URL without the prefix, in any source.
- A [view](/plugins/views) exists in every language, at its prefix, and receives the language as `lang`.
- A plugin with texts of its own lists their keys in `translations`, and `ui.translations` of your site translates them.

## Text Direction

The language sets the direction of the text. `<html dir>` is `rtl` for a language written from right to left, like Arabic (`ar`) or Hebrew (`he`), and `ltr` for others. The components of the UI follow it.

## Switching Languages

The app in the browser holds the data of one language, like its page tree. Picking another language in the language switch loads the same page in that language as a new document, and so does a link to a page of another language.
