List your languages, and Fumapress adds the URLs and links between translations. A page without a translation shows the page of the fallback language.

## Setup

### List the Languages [step]

<show when={props.framework === "waku"}>

Define them and pass them to `createPress()`:

```tsx title="press.config.tsx"
import { createPress } from "fumapress";
import { defineDocs } from "fumadocs-mdx/macro";
import { defineI18n } from "fumadocs-core/i18n";

const docs = defineDocs({ dir: "content" });

// [!code highlight:4]
const i18n = defineI18n({
  languages: ["en", "zh"],
  defaultLanguage: "en",
});

export const app = createPress({ docs: docs.toFumadocsSource() }, { i18n });

export default app.config({
  ui: {
    translations: i18n.translations(),
  },
});
```

</show>

<show when={props.framework === "astro"}>

Define them in a separate file, since custom pages read them too, and pass them to `createPress()`:

```ts tab="src/lib/i18n.ts"
import { defineI18n } from "fumadocs-core/i18n";

export const i18n = defineI18n({
  languages: ["en", "zh"],
  defaultLanguage: "en",
});
```

```tsx tab="press.config.tsx"
import { getCollection } from "astro:content";
import { toFumadocsSource } from "@fumadocs/astro/source";
import { createPress } from "@fumapress/astro/config";
import { i18n } from "./src/lib/i18n";

export const app = createPress(
  { docs: toFumadocsSource(await getCollection("docs"), await getCollection("meta")) },
  { i18n }, // [!code highlight]
);

export default app.config({
  ui: {
    translations: i18n.translations(),
  },
});
```

</show>

### Translate the Pages [step]

Add the language to the file name. This works for pages and `meta.json`:

```files
└── content
    ├── meta.json
    ├── meta.zh.json
    ├── get-started.mdx
    └── get-started.zh.mdx
```

A language without a file inherits the page from the [fallback language](https://fumadocs.dev/docs/headless/internationalization/config#fallback-language). If only the English file exists, `/zh/get-started` still exists and shows the English page.

<Callout>
  Inherited pages get `noindex` and are left out of the sitemap, RSS feed, `llms-full.txt` and Open
  Graph images, since search engines shouldn't see them as translations.
</Callout>

### Translate the UI [step]

The search dialog, table of contents and other UI have their own strings. The language pack translates them for Chinese:

```npm
npm i @fumapress/language
```

```tsx title="press.config.tsx"
import { zhTW } from "@fumapress/language/zh-tw";

export default app.config({
  ui: {
    translations: i18n.translations().preset("zh", zhTW()), // [!code highlight]
  },
});
```

The language pack has `zhCN` and `zhTW`. For other languages, or to change single strings, use `.add()`:

```tsx title="press.config.tsx"
i18n
  .translations()
  .preset("zh", zhTW())
  .add({
    en: { displayName: "English" },
    zh: {
      displayName: "Chinese",
      "Search(search dialog)": "搜尋文檔",
      "Blog(blog)": "博客",
    },
  });
```

See the [Fumadocs Translations API](https://fumadocs.dev/docs/ui/translations) for details.

## Language Prefixes

Each language has a URL prefix. To drop the prefix of the default language, set `hideLocale`:

```tsx
const i18n = defineI18n({
  languages: ["en", "zh"],
  defaultLanguage: "en",
  hideLocale: "default-locale", // [!code highlight]
});
```

| Source                   | `"never"` (default)      | `"default-locale"`    |
| ------------------------ | ------------------------ | --------------------- |
| `content/index.mdx`      | `/en`, `/zh`             | `/`, `/zh`            |
| `content/setup.mdx`      | `/en/setup`, `/zh/setup` | `/setup`, `/zh/setup` |
| Blog index (plugin page) | `/en/blog`, `/zh/blog`   | `/blog`, `/zh/blog`   |

With `"never"`, `/` redirects to `/en`. When `/en` has no page, like with content under a `baseDir`, the root and the navbar title link to the first page of `en`.

<Callout type="warn">
  `hideLocale: "always"` isn't supported, because Fumapress uses the prefix to tell languages apart.
</Callout>

### Localized Links

`localizePath()` adds the prefix, unless `hideLocale` hides it. Use it in [`ui.layoutProps`](./configuration.mdx#links-per-language), in plugins, and with `getPressContext()` on custom pages.

```tsx title="press.config.tsx"
this.localizePath("zh", "/setup"); // "/zh/setup"
```

### hreflang Tags

Pages link their translations for search engines, with tags like this one:

```html
<link rel="alternate" hreflang="zh-Hans" href="https://acme.dev/cn/setup" />
```

`hreflang` must be a BCP 47 tag. When a language code isn't one, map it:

```tsx title="press.config.tsx"
export default app.config({
  site: { hreflang: { cn: "zh-Hans", tw: "zh-Hant" } },
});
```

## Custom Pages

<show when={props.framework === "waku"}>

Each page in `src/pages` is created once per language, under its prefix, with a `lang` prop:

```tsx title="src/pages/about.tsx"
import type { WakuRouteProps } from "fumapress";
import type { app } from "../../press.config";

export default function Page({ lang }: WakuRouteProps<typeof app>) {
  return <h1>{lang === "zh" ? "关于" : "About"}</h1>;
}
```

To keep a single copy of a page, in the default language, set `autoI18n: false` in `getConfig()`.

</show>

<show when={props.framework === "astro"}>

Your pages aren't copied per language. Add a `lang` param and share the `i18n` config:

```astro title="src/pages/[...lang]/about.astro"
---
import HomeLayout from "@fumapress/astro/components/HomeLayout.astro";
import { i18n } from "../../lib/i18n";

export function getStaticPaths() {
  return i18n.languages.map((lang) => ({
    params: { lang: lang === i18n.defaultLanguage ? undefined : lang },
  }));
}
---

<HomeLayout title="About">
  <main>About</main>
</HomeLayout>
```

This example has no prefix on the default language, for `hideLocale: "default-locale"`. `HomeLayout.astro` reads the language from the URL unless you pass `lang`.

With `hideLocale: "never"`, `/` redirects to the default language unless you have a `src/pages/index.astro`.

</show>
