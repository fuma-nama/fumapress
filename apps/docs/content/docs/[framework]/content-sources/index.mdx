## Multiple Sources

Pass an object to use multiple sources on one site. Each key names a source, and `baseDir` is its URL prefix.

<show when={props.framework === "waku"}>

```tsx title="press.config.tsx"
// [!code word:baseDir]
export default createPress({
  docs: docs.toFumadocsSource({ baseDir: "docs" }),
  guides: notion.dynamicSource({ baseDir: "guides" }),
}).plugins(notionPlugin({ notion }));
```

</show>

<show when={props.framework === "astro"}>

```tsx title="press.config.tsx"
// [!code word:baseDir]
export default createPress({
  docs: toFumadocsSource(await getCollection("docs"), await getCollection("meta"), {
    baseDir: "docs",
  }),
  guides: notion.dynamicSource({ baseDir: "guides" }),
}).plugins(notionPlugin({ notion }));
```

</show>

Now your {props.framework === "astro" ? "collection is" : "MDX pages are"} under `/docs`, and the Notion pages are under `/guides`. Use the key `"guides"` to give those pages [their own layout](../layouts.mdx#layout-per-source).
