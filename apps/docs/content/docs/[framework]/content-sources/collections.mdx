Your pages are MDX files in [content collections](https://docs.astro.build/en/guides/content-collections/), and new sites already include one. A collection needs three files:

```js tab="astro.config.mjs"
import { defineConfig } from "astro/config";
import press from "@fumapress/astro";

export default defineConfig({
  integrations: [
    press({
      collections: { docs: { dir: "content" } },
      lastModified: true,
      includeProcessedMarkdown: true,
    }),
  ],
});
```

```ts tab="src/content.config.ts"
import { defineCollection } from "astro:content";
import { metaLoader, pageLoader } from "@fumadocs/astro/loaders";

export const collections = {
  docs: defineCollection({ loader: pageLoader() }),
  meta: defineCollection({ loader: metaLoader() }),
};
```

```tsx tab="press.config.tsx"
import { getCollection } from "astro:content";
import { toFumadocsSource } from "@fumadocs/astro/source";
import { createPress } from "@fumapress/astro/config";

export default createPress(
  toFumadocsSource(await getCollection("docs"), await getCollection("meta")),
);
```

Without `collections`, `press()` reads the `docs` collection from `content/docs`. See [Integration](../configuration.mdx#integration) for the other options.

## Frontmatter Fields

`pageLoader()` accepts the [standard fields](../content.mdx#frontmatter). Extend the schema to add a field. The new field is typed on `page.data` in your [layout](../layouts.mdx#layout-per-source).

```ts title="src/content.config.ts"
import { defineCollection } from "astro:content";
import { z } from "astro/zod";
import { pageSchema } from "fumadocs-core/source/schema";
import { metaLoader, pageLoader } from "@fumadocs/astro/loaders";

export const collections = {
  docs: defineCollection({
    loader: pageLoader(),
    schema: pageSchema.extend({ draft: z.boolean().optional() }), // [!code ++]
  }),
  meta: defineCollection({ loader: metaLoader() }),
};
```

## Multiple Collections

To add a blog, or to free `/` for a [landing page](../custom-pages.mdx), give each collection a folder and a URL prefix. After these steps, `content/docs/index.mdx` is at `/docs`, and `content/blog/hello.mdx` is at `/blog/hello`.

### Name the Folders [step]

```js title="astro.config.mjs"
press({
  collections: {
    docs: { dir: "content/docs" }, // [!code highlight]
    blog: { dir: "content/blog" }, // [!code ++]
  },
});
```

### Load the Collections [step]

`pageLoader("blog")` reads the `blog` folder above, and each key of this object is a name for `getCollection()`.

```ts title="src/content.config.ts"
export const collections = {
  docs: defineCollection({ loader: pageLoader() }),
  meta: defineCollection({ loader: metaLoader() }),
  // [!code ++:2]
  blog: defineCollection({ loader: pageLoader("blog") }),
  blogMeta: defineCollection({ loader: metaLoader("blog") }),
};
```

### Add the Sources [step]

```tsx title="press.config.tsx"
export default createPress({
  docs: toFumadocsSource(await getCollection("docs"), await getCollection("meta"), {
    baseDir: "docs",
  }),
  // [!code ++:3]
  blog: toFumadocsSource(await getCollection("blog"), await getCollection("blogMeta"), {
    baseDir: "blog",
  }),
});
```

<Callout>
  A collection you leave out of `createPress()` has no docs pages. You can [render it on custom
  pages](../custom-pages.mdx#rendering-a-collection).
</Callout>
