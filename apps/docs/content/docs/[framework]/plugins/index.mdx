Your site starts with a set of default plugins. Add more with `.plugins()`:

```tsx title="press.config.tsx"
import { blogPlugin } from "@fumapress/blog";

export default createPress(content).plugins(blogPlugin({ source: "blog" }));
```

## Default Plugins

`recommendedPreset()` has these plugins. The key is its option:

| Feature                                          | Key       |
| ------------------------------------------------ | --------- |
| [Sitemap](./seo.mdx#sitemap)                     | `sitemap` |
| [robots.txt](./seo.mdx#robotstxt)                | `robots`  |
| [RSS](./seo.mdx#rss)                             | `rss`     |
| [Open Graph images](./seo.mdx#open-graph-images) | `ogImage` |
| [llms.txt](./ai.mdx#llmstxt)                     | `llms`    |
| [Search](../search.mdx) with FlexSearch          | `search`  |

### Options of a Default Plugin

`recommendedPreset()` takes the options of each default plugin. Pass it to `preset` in `.config()`:

<show when={props.framework === "waku"}>

```tsx title="press.config.tsx"
import { createPress, recommendedPreset } from "fumapress";

createPress(content).config({
  preset: recommendedPreset({ rss: { limit: 50 } }),
});
```

</show>

<show when={props.framework === "astro"}>

```tsx title="press.config.tsx"
import { createPress, recommendedPreset } from "@fumapress/astro/config";

createPress(content).config({
  preset: recommendedPreset({ rss: { limit: 50 } }),
});
```

</show>

### Replacing a Default Plugin

Set the default plugin to `false`, then list your own. This site uses Orama for search:

<show when={props.framework === "waku"}>

```tsx title="press.config.tsx"
import { createPress, recommendedPreset } from "fumapress";
import { oramaSearchPlugin } from "fumapress/plugins/orama-search";

export const app = createPress(content).plugins(oramaSearchPlugin());

export default app.config({
  preset: recommendedPreset({ search: false }),
});
```

</show>

<show when={props.framework === "astro"}>

```tsx title="press.config.tsx"
import { createPress, recommendedPreset } from "@fumapress/astro/config";
import { oramaSearchPlugin } from "@fumapress/astro/plugins/orama-search";

export const app = createPress(content).plugins(oramaSearchPlugin());

export default app.config({
  preset: recommendedPreset({ search: false }),
});
```

</show>

### Removing Default Plugins

Set a default plugin to `false` to remove it, or pass an empty list to remove them all:

```tsx tab="One plugin" title="press.config.tsx"
createPress(content).config({
  preset: recommendedPreset({ rss: false }),
});
```

```tsx tab="All plugins" title="press.config.tsx"
createPress(content).config({
  preset: [],
});
```

## Conditional Plugins and Plugin Order

Falsy values are skipped, so a plugin can be conditional:

```tsx title="press.config.tsx"
const blog = process.env.ENABLE_BLOG && blogPlugin({ source: "blog" });

createPress(content).plugins(blog);
```

The order matters in two places. Middleware is nested in list order, so your first plugin wraps the others. Navbar links also use the list order, after your `ui.layoutProps` links.
