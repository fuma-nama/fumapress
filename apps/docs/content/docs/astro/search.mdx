## Search Engines

FlexSearch is the default. Add a search plugin to change the engine or pass options to the [Fumadocs integration](https://fumadocs.dev/docs/headless/search/flexsearch). A site can only have one search plugin.

```tsx tab="FlexSearch" title="press.config.tsx"
import { flexsearchPlugin } from "@fumapress/astro/plugins/flexsearch";

createPress(content).plugins(flexsearchPlugin());
```

```tsx tab="Orama" title="press.config.tsx"
import { oramaSearchPlugin } from "@fumapress/astro/plugins/orama-search";

createPress(content).plugins(oramaSearchPlugin());
```

```tsx tab="None" title="press.config.tsx"
import { createPress, recommendedPreset } from "@fumapress/astro/config";

createPress(content).config({
  preset: recommendedPreset().filter((entry) => entry.provides !== "search"),
});
```

An engine like Algolia is a separate plugin. See [Custom Search Engine](/docs/astro/plugins/authoring#custom-search-engine).
