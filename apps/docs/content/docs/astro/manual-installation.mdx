This guide creates by hand the files that `npm create fumapress` generates.

<Callout>Astro needs Node.js 22.23.4 or later.</Callout>

## Setup

### Install Dependencies [step]

```npm
npm i @fumapress/astro
npm i @fumadocs/astro astro
npm i @astrojs/react react react-dom takumi-js fumadocs-core
npm i fumadocs-ui@npm:@fumadocs/base-ui

npm i tailwindcss @tailwindcss/vite -D
npm i typescript @types/mdx @types/react @types/react-dom -D
```

### Create the Config Files [step]

```js tab="astro.config.mjs"
// @ts-check
import { defineConfig } from "astro/config";
import tailwindcss from "@tailwindcss/vite";
import press from "@fumapress/astro";

export default defineConfig({
  // the URL of your deployed site, for the sitemap and other full URLs
  // site: "https://example.com",
  integrations: [
    press({
      collections: { docs: { dir: "content" } },
      lastModified: true,
      includeProcessedMarkdown: true,
    }),
  ],
  vite: {
    plugins: [tailwindcss()],
  },
});
```

```tsx tab="press.config.tsx"
import { getCollection } from "astro:content";
import { toFumadocsSource } from "@fumadocs/astro/source";
import { createPress } from "@fumapress/astro/config";

export default createPress(
  toFumadocsSource(await getCollection("docs"), await getCollection("meta")),
).config({
  site: {
    name: "My Docs",
  },
});
```

```ts tab="src/content.config.ts"
import { defineCollection } from "astro:content";
import { metaLoader, pageLoader } from "@fumadocs/astro/loaders";

export const collections = {
  docs: defineCollection({ loader: pageLoader() }),
  meta: defineCollection({ loader: metaLoader() }),
};
```

```css tab="src/app.css"
@import "@fumapress/astro/css/default.css";
```

```json tab="tsconfig.json"
{
  "extends": "astro/tsconfigs/strict",
  "include": [".astro/types.d.ts", "**/*"],
  "exclude": ["dist"],
  "compilerOptions": {
    "jsx": "react-jsx",
    "jsxImportSource": "react",
    "paths": { "@/*": ["./src/*"] }
  }
}
```

The [Fumadocs CLI](/docs/astro/layouts#customizing-fumadocs-ui) uses the `paths` alias in the files it copies.

### Update package.json [step]

```json title="package.json"
{
  // [!code ++]
  "type": "module",
  "scripts": {
    // [!code ++:4]
    "dev": "astro dev",
    "build": "astro build",
    "preview": "astro preview",
    "types:check": "astro sync && tsc --noEmit"
  }
}
```

### Write Your First Page [step]

```mdx title="content/index.mdx"
---
title: My Page
description: Hello World
---

## Overview

This is my first document.
```

### Start the Site [step]

```npm
npm run dev
```

Your docs start at `/`. To keep `/` for a landing page, [give your content a URL prefix](/docs/astro/content-sources/collections#multiple-collections).
