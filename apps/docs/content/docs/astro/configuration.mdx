`press.config.tsx` at the project root configures your site. Only `createPress()` is required. The file can `await` your collections.

```tsx title="press.config.tsx"
import { getCollection } from "astro:content";
import { toFumadocsSource } from "@fumadocs/astro/source";
import { createPress } from "@fumapress/astro/config";
import { rssPlugin } from "@fumapress/astro/plugins/rss";

export const app = createPress(
  toFumadocsSource(await getCollection("docs"), await getCollection("meta")),
  { i18n },
).plugins(rssPlugin());

export default app.config({
  site: { name: "Acme" },
  head: [{ tag: "link", attrs: { rel: "icon", href: "/favicon.ico" } }],
  ui: { baseOptions, renderPage },
});
```

### URL

Set [`site`](https://docs.astro.build/en/reference/configuration-reference/#site) in your Astro config. Without it, canonical links, the sitemap, RSS and Open Graph images fall back to relative URLs.

```js title="astro.config.mjs"
export default defineConfig({
  site: "https://docs.example.com",
  integrations: [press()],
});
```

### Logo

`nav.title` can be any React element:

```tsx title="press.config.tsx"
createPress(content).config({
  ui: {
    baseOptions: {
      nav: {
        title: (
          <>
            <img src="/logo.png" width={64} height={64} className="size-8" alt="" />
            Acme
          </>
        ),
      },
    },
  },
});
```

```tsx title="src/lib/base-options.tsx"
import type { UIOptions } from "@fumapress/astro/config";
import type { app } from "../../press.config";

export const baseOptions: UIOptions<typeof app>["baseOptions"] = function ({ lang }) {
  return { links: [{ url: this.localizePath(lang, "/blog"), text: "Blog" }] };
};
```

## Integration

`press()` also takes the [options of `@fumadocs/astro`](https://fumadocs.dev/docs/manual-installation/astro), like `collections` and `rehypeCodeOptions`. It adds the React and MDX integrations, so don't list them yourself.

```js title="astro.config.mjs"
import { defineConfig } from "astro/config";
import press from "@fumapress/astro";

export default defineConfig({
  integrations: [
    press({
      components: "./src/components/mdx.tsx",
    }),
  ],
});
```

## Types

Export the result of `.plugins()` as `app`, and pass `typeof app` to the type helpers from `@fumapress/astro/config`:

```astro title="src/layouts/Docs.astro"
---
import type { LayoutProps } from "@fumapress/astro/config";
import type { app } from "../../press.config";

type Props = LayoutProps<typeof app, "docs">;
---
```

| Helper            | For                                                            |
| ----------------- | -------------------------------------------------------------- |
| `LayoutProps`     | props of an [`.astro` layout](./layouts.mdx#islands)           |
| `IslandProps`     | props of its island                                            |
| `RenderPageProps` | props of `ui.renderPage`, narrowed to a source or plugin page  |
| `UIOptions`       | an option of `ui`, like `UIOptions<typeof app>["baseOptions"]` |
| `PressContext`    | `this` in callbacks, the result of `getPressContext()`         |
| `BaseOptions`     | the Fumadocs layout props                                      |
| `ProviderProps`   | the root provider props                                        |
