## Integration

`press()` takes the options of the [Fumadocs integration](https://fumadocs.dev/docs/manual-installation/astro#options), like `collections`, `includeProcessedMarkdown` and `rehypeCodeOptions`, plus the MDX components module:

```js title="astro.config.mjs"
import { defineConfig } from "astro/config";
import press from "@fumapress/astro";

export default defineConfig({
  integrations: [
    press({
      // the MDX components, defaults to `fumadocs-ui/mdx`
      components: "./src/components/mdx.tsx",
    }),
  ],
});
```

See [MDX Components](/docs/astro/content#mdx-components) for the components module.

## Press Config

`createPress` from `@fumapress/astro/config` takes the same stages as on Waku: `createPress(content, options).plugins(...).config({...})`. It runs on the server of Astro before your pages render. It can `await` your collections, and the callbacks of plugins receive the site context as `this`.

Waku-only options are type errors on Astro: `ui.renderRoot`, image optimizer plugins and the `waku` hooks of plugins. See [Config](/docs/config) for every shared option.

### Render Mode

The [render mode](/docs/config#render-mode) follows your Astro config:

| Astro config                   | `mode`    |
| ------------------------------ | --------- |
| no adapter                     | `static`  |
| an adapter                     | `default` |
| an adapter, `output: "server"` | `dynamic` |

Set `mode: "static"` to build without server routes while keeping an adapter. `default` and `dynamic` without an adapter fail with an error. See [Deployment](/docs/astro/deployment).

### Site URL

`site.baseUrl` defaults to the [`site`](https://docs.astro.build/en/reference/configuration-reference/#site) of Astro with its `base`, and to the address of the dev server in dev. Set `site` in your Astro config rather than `site.baseUrl`:

```js title="astro.config.mjs"
import { defineConfig } from "astro/config";
import press from "@fumapress/astro";

export default defineConfig({
  // [!code ++]
  site: "https://docs.example.com",
  integrations: [press()],
});
```

Without it, the sitemap and `og:image` use relative URLs, and pages have no canonical URL.

## Styles

`src/app.css` is loaded on every page. Start it from the default styles:

```css title="src/app.css"
@import "@fumapress/astro/css/default.css";
/* the styles of integrations [!code ++] */
@import "fumadocs-openapi/css/preset.css";
```

Without the file, the default styles are used: Tailwind CSS, the `neutral` theme and the preset of Fumadocs UI. For another [theme](https://fumadocs.dev/docs/ui/theme), import them yourself:

```css title="src/app.css"
@import "tailwindcss";
@import "fumadocs-ui/css/black.css";
@import "fumadocs-ui/css/preset.css";
@import "@fumapress/astro/css/preset.css";
```
