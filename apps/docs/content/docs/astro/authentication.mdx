On Astro, middleware runs for the routes rendered on demand. Prerendered pages and the files of `public/` never reach it.

## Protecting the Whole Site

### Render Pages on Demand [step]

Add an [adapter](/docs/astro/deployment#adapters), and set `output: "server"`:

```js title="astro.config.mjs"
export default defineConfig({
  output: "server", // [!code ++]
  adapter: node({ mode: "standalone" }), // [!code ++]
  integrations: [press()],
});
```
