Fumapress renders your vault with its wikilinks, embeds, callouts, block IDs and comments.

<include cwd>content/shared/content-sources/obsidian.mdx#setup</include>

The vault is read when a page renders, so the site [needs a server](/docs/astro/deployment#what-needs-a-server). To prerender the pages instead, pass `await vault.staticSource()`.

## Content Updates

Fumapress reads your vault once. To see changes, use hot reload on the dev server, and refresh the content on a deployed site.

### Hot Reload

<include cwd>content/shared/content-sources/obsidian.mdx#reload-intro</include>

```js tab="astro.config.mjs"
import { localContentPlugin } from "fumadocs-obsidian/dev/vite"; // [!code ++]

export default defineConfig({
  integrations: [press()],
  vite: {
    plugins: [
      tailwindcss(),
      localContentPlugin(), // [!code ++]
    ],
  },
});
```

```tsx tab="press.config.tsx"
import { watchWithVite } from "fumadocs-obsidian/dev/vite";

if (import.meta.env.DEV) watchWithVite(vault);
```
