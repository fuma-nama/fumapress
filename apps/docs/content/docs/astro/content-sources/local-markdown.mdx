title: Local Markdown

[Local Markdown](https://fumadocs.dev/docs/integrations/content/local-md) reads files on the server instead of compiling them in a bundler. Its pages render with your [MDX components](/docs/astro/content#components).

<Callout type="warn">MDX `import` statements are not available.</Callout>

## Setup

### Install the Package [step]

```npm
npm i @fumadocs/local-md shiki
```

### Create the Source [step]

```tsx title="press.config.tsx"
import { createPress } from "@fumapress/astro/config";
import { localMd } from "@fumadocs/local-md";

const docs = localMd({ dir: "content/docs" });

export default createPress(docs.dynamicSource());
```

`dynamicSource()` reads files on the server, so the site [needs a server](/docs/astro/deployment#what-needs-a-server). To prerender the pages instead, pass `await docs.staticSource()`.

## Reload on Changes

The dev server doesn't watch these files by default. Add the Vite plugin, then connect your source:

```js tab="astro.config.mjs"
import { localContentPlugin } from "@fumadocs/local-md/dev/vite"; // [!code ++]

export default defineConfig({
  integrations: [press()],
  vite: {
    plugins: [
      tailwindcss(),
      localContentPlugin(), // [!code ++]
    ],
  },
});
```

```tsx tab="press.config.tsx"
import { watchWithVite } from "@fumadocs/local-md/dev/vite";

if (import.meta.env.DEV) watchWithVite(docs);
```
