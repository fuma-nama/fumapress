## Overview

Docs pages render with the [Docs Layout](/docs/layouts/docs) of Fumadocs UI by default. On Astro, you customize them with two React modules passed to `press()`:

- `page`: the component of docs pages.
- `layout`: the `Provider`, `SearchDialog` and `useSearch` of every layout.

```js title="astro.config.mjs"
press({
  layout: "./src/components/layout.tsx",
  page: "./src/components/docs.tsx",
});
```

Both render in the island of the layout, so they run in the browser too. Navigating between pages keeps the island and its state, like the open folders of the sidebar.

## Layout Props

`defaultLayoutProps` are the [shared props](/docs/layouts#shared-props) of docs pages, `HomeLayout.astro` and the 404 page. They can contain JSX, it follows the rules of [React content](/docs/astro/content#react-content):

```tsx title="press.config.tsx"
import { defineConfig } from "@fumapress/astro/config";

export default defineConfig({
  // ...
  // [!code ++:13]
  defaultLayoutProps: {
    nav: {
      title: <span className="font-semibold">My Docs</span>,
    },
    links: [
      {
        text: "Blog",
        url: "/blog",
        active: "nested-url",
      },
    ],
  },
});
```

## Page Module

The default export of the `page` module renders docs pages, with the [Notebook Layout](/docs/layouts/notebook) for example:

```tsx title="src/components/docs.tsx"
import type { DocsPageProps } from "@fumapress/astro/config";
import { DocsLayout } from "fumadocs-ui/layouts/notebook";
import { DocsBody, DocsDescription, DocsPage, DocsTitle } from "fumadocs-ui/layouts/notebook/page";

export default function Page({ tree, page, layout, slots, children }: DocsPageProps) {
  return (
    <DocsLayout {...layout} tree={tree}>
      <DocsPage toc={page.toc} full={page.full}>
        <DocsTitle>{page.title}</DocsTitle>
        <DocsDescription>{page.description}</DocsDescription>
        {slots["page.actions"]}
        <DocsBody>{children}</DocsBody>
        {slots["page.footer"]}
      </DocsPage>
    </DocsLayout>
  );
}
```

It receives:

- `tree`: the page tree of the language.
- `page`: the title, description and table of contents of the page, with `markdownUrl`, `githubUrl` and `lastModified` when plugins and `site.git` provide them.
- `layout`: the `defaultLayoutProps`.
- `slots`: the UI of plugins for `page.actions` and `page.footer`, place them in your page.
- `children`: the body of the page, wrapped by the `body.wrapper` slot.

`page.url` tells your collections apart, like `page.url.startsWith("/guides")` for a collection with `baseDir: "guides"`.

The body is an island of its own: providers in your page module and in `body.wrapper` don't reach it, give the [MDX components](/docs/astro/content#mdx-components) their own `wrapper` instead.

## Layout Module

The `layout` module exports what every layout uses, all exports are optional.

`Provider` wraps the children of the root provider, for UI on every page:

```tsx title="src/components/layout.tsx"
import type { ReactNode } from "react";

export function Provider({ children }: { children: ReactNode }) {
  return (
    <>
      <div className="border-b p-2 text-center text-sm">Fumapress v1 is out!</div>
      {children}
    </>
  );
}
```

### Search

The search dialog uses the search plugin, [FlexSearch](/docs/plugins/flexsearch) by default:

- In `static` mode, it downloads the static index of FlexSearch or [Orama](/docs/plugins/orama-search), and searches in the browser.
- Otherwise, it fetches the results from `/api/search`.

Search is disabled without a search plugin, like with `preset: false`.

Export `useSearch` to use another search service with the default dialog, like a [search hook](https://fumadocs.dev/docs/headless/search) of Fumadocs:

```tsx title="src/components/layout.tsx"
import type { LayoutModule } from "@fumapress/astro/config";
import { useFetchSearch } from "fumadocs-core/search/client/fetch";

export const useSearch: LayoutModule["useSearch"] = ({ locale }) =>
  useFetchSearch({ api: "https://search.example.com/api/search", locale });
```

Export `SearchDialog` to replace the dialog itself, see [Search UI](https://fumadocs.dev/docs/ui/search).
