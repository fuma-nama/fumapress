## React Content

The React content of a plugin renders on the server, in an island. Only client components (`"use client"`) and components of the [MDX components](/docs/astro/content#components) module hydrate. Everything else can't use state or effects.

<Callout type="warn">
  Props of hydrating components must be serializable: strings, numbers, dates, maps, JSX elements
  and client components work. A client component with a function prop throws an error naming it.
</Callout>
