### Requests That Reach Middleware

On Astro, `middleware` runs for the routes rendered on demand. Prerendered pages and the files of `public/` never reach it. See [Authentication](/docs/astro/authentication) for which routes a check should cover.

A build without an [adapter](/docs/astro/deployment#adapters) warns that the middleware of your plugins never runs.

<Callout type="warn">
  `next(path)` can render pages from dynamic sources, plugin views and API routes. For prerendered
  files and your `.astro` pages, it responds with an empty 404.
</Callout>
