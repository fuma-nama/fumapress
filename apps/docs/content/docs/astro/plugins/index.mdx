## Default Plugins

<include cwd>content/shared/plugins/index.mdx#table</include>

There is no image plugin, since [Astro Images](https://docs.astro.build/en/guides/images/) handles images.

<include cwd>content/shared/plugins/index.mdx#replace</include>

```tsx title="press.config.tsx"
import { rssPlugin } from "@fumapress/astro/plugins/rss";

createPress(content).plugins(rssPlugin({ limit: 50 }));
```

<include cwd>content/shared/plugins/index.mdx#remove</include>

```tsx title="press.config.tsx"
import { createPress, recommendedPreset } from "@fumapress/astro/config";

createPress(content).config({
  preset: recommendedPreset().filter((entry) => entry.provides !== "rss"),
});
```
