Fumapress turns your Markdown files into a complete docs site on [Astro](https://astro.build). It is built on [Fumadocs](https://fumadocs.dev) and comes with layouts, search, SEO files and plugins. Your content is stored in Astro content collections, and Astro handles routing, builds and deployment.

## Creating a Site

<Callout>Astro needs Node.js 22.23.4 or later.</Callout>

### Create the Project [step]

```npm
npm create fumapress -- --framework astro
```

### Start the Dev Server [step]

From the new folder:

```npm
npm run dev
```

The project looks like this:

```files
├── content
│   └── index.mdx
├── src
│   ├── app.css
│   └── content.config.ts
├── press.config.tsx
└── astro.config.mjs
```

### Name the Site [step]

Set the name in `press.config.tsx`. It shows in the navbar and page metadata.

```tsx title="press.config.tsx"
export default createPress(
  toFumadocsSource(await getCollection("docs"), await getCollection("meta")),
).config({
  site: {
    name: "My Docs", // [!code highlight]
  },
});
```
