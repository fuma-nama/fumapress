## Overview

Fumapress on [Astro](https://astro.build) runs the same `press.config.tsx` as on Waku: content, plugins, site info and UI options. Astro owns the routing, builds and deployment, and Fumadocs UI renders in React islands.

Compared to Waku:

- No React Server Components. Content comes from Astro content collections, through `@fumadocs/astro`.
- The output of `ui.renderPage` renders in an island. See [React Content](/docs/astro/content#react-content).
- No `ui.renderRoot`, Vite plugin, route files or image optimizers. Use Astro's equivalents.

## Imports

Astro imports the same API from these packages:

| Waku (`fumapress`)                   | Astro                                           |
| ------------------------------------ | ----------------------------------------------- |
| `fumapress`                          | `@fumapress/astro/config`                       |
| `fumapress/plugins/*`                | `@fumapress/astro/plugins/*`                    |
| `fumapress/vite`                     | The `press()` integration of `@fumapress/astro` |
| `getPressContext` (from `fumapress`) | `@fumapress/astro/runtime`                      |

Plugin packages (`@fumapress/blog`, `@fumapress/tegami`, `@fumapress/ai`, `@fumapress/feedback`, `@fumapress/mintlify`) and the Fumadocs `/press` plugins (`fumadocs-openapi/press`, `@fumadocs/asyncapi/press`, `@fumadocs/graphql/press`, `@fumadocs/notion/press`, `@fumadocs/sanity/press`, `fumadocs-obsidian/press`) are imported as they are.

`fumapress/image`, `fumapress/client`, `fumapress/router` and the image optimizer plugins have no Astro counterpart. Use [Astro Image](https://docs.astro.build/en/guides/images/) for image optimization.

The shared guides at [Config](/docs/config), [Layouts](/docs/layouts), [Search](/docs/search) and [Plugins](/docs/plugins) apply with this mapping.

## Automatic Installation

```npm
npm create fumapress -- --framework astro
```

## Manual Installation

Astro 7.4 requires Node.js 22.23.4 or later.

Install the dependencies:

```npm
npm i @fumapress/astro @fumadocs/astro astro @astrojs/react fumadocs-core fumadocs-ui@npm:@fumadocs/base-ui react react-dom takumi-js

npm i tailwindcss @tailwindcss/vite @types/mdx @types/react @types/react-dom typescript -D
```

`takumi-js` renders the Open Graph images of the [recommended preset](/docs/config#preset). `@fumapress/astro/plugins/takumi` re-exports its font helpers, `googleFonts` and `fontFromUrl`.

Create the config files:

```js tab="astro.config.mjs"
// @ts-check
import { defineConfig } from "astro/config";
import tailwindcss from "@tailwindcss/vite";
import press from "@fumapress/astro";

export default defineConfig({
  // the URL where your site is deployed, needed for SEO features like sitemap:
  // site: "https://example.com",
  integrations: [
    press({
      collections: { docs: { dir: "content" } },
      lastModified: true,
      includeProcessedMarkdown: true,
    }),
  ],
  vite: {
    plugins: [tailwindcss()],
  },
});
```

```tsx tab="press.config.tsx"
import { getCollection } from "astro:content";
import { toFumadocsSource } from "@fumadocs/astro/source";
import { createPress } from "@fumapress/astro/config";

export default createPress(
  toFumadocsSource(await getCollection("docs"), await getCollection("meta")),
).config({
  site: {
    name: "My Docs",
  },
});
```

```ts tab="src/content.config.ts"
import { defineCollection } from "astro:content";
import { metaLoader, pageLoader } from "@fumadocs/astro/loaders";

export const collections = {
  docs: defineCollection({ loader: pageLoader() }),
  meta: defineCollection({ loader: metaLoader() }),
};
```

```css tab="src/app.css"
@import "@fumapress/astro/css/default.css";
```

```json tab="tsconfig.json"
{
  "extends": "astro/tsconfigs/strict",
  "include": [".astro/types.d.ts", "**/*"],
  "exclude": ["dist"],
  "compilerOptions": {
    "jsx": "react-jsx",
    "jsxImportSource": "react"
  }
}
```

`press()` adds the Fumadocs integration for the content collections, and the React and MDX integrations of Astro. `press.config.tsx` stays at the project root, as on Waku.

Set the package type and scripts:

```json title="package.json"
{
  // [!code ++]
  "type": "module",
  "scripts": {
    // [!code ++:4]
    "dev": "astro dev",
    "build": "astro build",
    "preview": "astro preview",
    "types:check": "astro sync && tsc --noEmit"
  }
}
```

Start the dev server:

```npm
npm run dev
```

You can now start writing MDX files under the `content` directory.

```mdx title="content/index.mdx"
---
title: My Page
description: Hello World
---

## Overview

This is my first document.
```
