## Overview

Fumapress on [Astro](https://astro.build) runs the same `press.config.tsx` as on Waku: content, site info, layout props and plugins. Astro owns the routing, builds and deployment, and Fumadocs UI renders in React islands.

Compared to Waku:

- Pages are Astro routes, without React Server Components.
- Content comes from Astro content collections, through `@fumadocs/astro`.
- Layouts are customized with modules instead of `renderPage`, see [Layouts](/docs/astro/layouts).

## Automatic Installation

```npm
npm create fumapress -- --framework astro
```

## Manual Installation

Astro 7.4 requires Node.js 22.23.4 or later.

Install the dependencies:

```npm
npm i @fumapress/astro @fumapress/core @fumadocs/astro astro @astrojs/react fumadocs-core fumadocs-ui@npm:@fumadocs/base-ui react react-dom takumi-js

npm i tailwindcss @tailwindcss/vite @types/mdx @types/react @types/react-dom typescript -D
```

`takumi-js` renders the Open Graph images of the [recommended preset](/docs/config#preset).

Create the config files:

```js tab="astro.config.mjs"
import { defineConfig } from "astro/config";
import tailwindcss from "@tailwindcss/vite";
import press from "@fumapress/astro";

export default defineConfig({
  integrations: [
    press({
      // the Markdown of pages for llms.txt
      includeProcessedMarkdown: true,
    }),
  ],
  vite: {
    plugins: [tailwindcss()],
  },
});
```

```tsx tab="press.config.tsx"
import { getCollection } from "astro:content";
import { toFumadocsSource } from "@fumadocs/astro/source";
import { defineConfig } from "@fumapress/astro/config";

export default defineConfig({
  content: toFumadocsSource(await getCollection("docs"), await getCollection("meta")),
  site: {
    name: "My Docs",
  },
});
```

```ts tab="src/content.config.ts"
import { defineCollection } from "astro:content";
import { metaLoader, pageLoader } from "@fumadocs/astro/loaders";

export const collections = {
  docs: defineCollection({ loader: pageLoader() }),
  meta: defineCollection({ loader: metaLoader() }),
};
```

```json tab="tsconfig.json"
{
  "extends": "astro/tsconfigs/strict",
  "include": [".astro/types.d.ts", "**/*"],
  "exclude": ["dist"],
  "compilerOptions": {
    "jsx": "react-jsx",
    "jsxImportSource": "react"
  }
}
```

`press()` adds the Fumadocs integration for the content collections, and the React and MDX integrations of Astro. `press.config.tsx` stays at the project root, as on Waku.

Set the package type and scripts:

```json title="package.json"
{
  // [!code ++]
  "type": "module",
  "scripts": {
    // [!code ++:4]
    "dev": "astro dev",
    "build": "astro build",
    "preview": "astro preview",
    "types:check": "astro sync && tsc --noEmit"
  }
}
```

Start the dev server:

```npm
npm run dev
```

You can now start writing MDX files under the `content/docs` directory.

```mdx title="content/docs/index.mdx"
---
title: My Page
description: Hello World
---

## Overview

This is my first document.
```

## Migrate from `@fumadocs/astro`

The managed setup of `@fumadocs/astro` 0.1 moved to Fumapress, and `@fumadocs/astro` 0.2 is the integration for your own routes. Install `@fumapress/astro` and `@fumapress/core`, then:

| Before                                                                        | Now                                                                           |
| ----------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| `fumadocs({ layout, page })`                                                  | `press({ layout, page })`                                                     |
| `src/fumadocs.config.ts`                                                      | `press.config.tsx` at the project root                                        |
| `source: loader(...)`                                                         | `content: toFumadocsSource(...)`                                              |
| `title`                                                                       | `site.name`                                                                   |
| `plugins/openapi`, `asyncapi`, `graphql`, `notion`, `sanity`                  | the `plugin` subpath of the integration, like `fumadocs-openapi/plugin`       |
| `plugins/takumi`, `llms.txt`, `flexsearch`, `orama-search`, `link-validation` | the [recommended preset](/docs/config#preset), or `@fumapress/core/plugins/*` |
| `plugins/git`                                                                 | `site.git`, and the `lastModified` collection option                          |
| `plugins/mcp`                                                                 | `mcpPlugin()` of [`@fumapress/ai`](/docs/plugins/mcp)                         |
| `baseOptions()` of the layout module                                          | `defaultLayoutProps`                                                          |
| the `head` component                                                          | [`head()`](/docs/astro/configuration#head) tags                               |
| `src/styles/global.css`, the `css` option                                     | `src/app.css`                                                                 |
| `@fumadocs/astro/components/*`                                                | `@fumapress/astro/components/*`                                               |

URLs change too:

- Pages follow the content source, add `baseDir: "docs"` to keep them under `/docs`, see [Content](/docs/astro/content#collections).
- Open Graph images move from `/og/<page>/image.webp` to `<page>.webp`.
- The default search is FlexSearch instead of Orama, add `oramaSearchPlugin()` to keep Orama.

Plugin pages are no longer replaced by MDX components of the same name, pass them to the plugin like the `ClientAPIPage` option of OpenAPI. On your own pages, `<Content />` needs a `provider`, see [Routing](/docs/astro/routing#rendering-content).
