## Installation

```npm
npm i fumadocs-mdx
```

Requires `fumadocs-mdx` >= 15.5.0. Fumadocs MDX pages render without additional setup.

## Setup

```ts tab="vite.config.ts"
import { defineConfig } from "vite";
import tailwindcss from "@tailwindcss/vite";
import press from "fumapress/vite";
import { fumadocsMdx } from "fumadocs-mdx/vite";

export default defineConfig({
  plugins: [press(), fumadocsMdx(), tailwindcss()],
});
```

```tsx tab="press.config.tsx"
import { createPress } from "fumapress";
import { pageSchema, metaSchema } from "fumapress/schema";
import { defineDocs } from "fumadocs-mdx/macro";

const docs = defineDocs({
  dir: "content/docs",
  docs: {
    async: true,
    schema: pageSchema,
    lastModified: true,
  },
  meta: {
    schema: metaSchema,
  },
});

export default createPress({ docs: docs.toFumadocsSource() }).config({
  site: { name: "My Site" },
});
```

Start the dev server and write content under your collection directory.

## Frontmatter

With `pageSchema`, pages support the following frontmatter fields:

| Field         | Description                                                                                                      |
| ------------- | ---------------------------------------------------------------------------------------------------------------- |
| `title`       | The page title (required)                                                                                        |
| `description` | Shown below the title and in page metadata                                                                       |
| `icon`        | A [Lucide](https://lucide.dev) icon name shown in the sidebar. See [Loader Options](/docs/config#loader-options) |

The schema also reads fields your extensions add:

- `date`: the creation date, used by [Blog](/docs/plugins/blog), [RSS](/docs/plugins/rss) and [changelog entries](/docs/plugins/tegami).
- `tags`, `authors`, `image`: blog post fields, included in `blogPageSchema`. See [Blog](/docs/plugins/blog).

To support `date`, extend the page schema:

```tsx title="press.config.tsx"
import { pageSchema } from "fumapress/schema";
import { defineDocs } from "fumadocs-mdx/macro";
import { z } from "zod";

const docs = defineDocs({
  dir: "content",
  docs: {
    schema: pageSchema.extend({
      date: z.coerce.date().optional(),
    }),
  },
});
```

The last modified date comes from git history when the collection sets `lastModified: true`.

## MDX Components

Pass a components module to the Vite plugin. Its default export is the MDX components used to render pages:

```ts tab="vite.config.ts"
import { defineConfig } from "vite";
import tailwindcss from "@tailwindcss/vite";
import press from "fumapress/vite";
import { fumadocsMdx } from "fumadocs-mdx/vite";

export default defineConfig({
  plugins: [
    // [!code ++]
    press({ components: "./src/components/mdx.tsx" }),
    fumadocsMdx(),
    tailwindcss(),
  ],
});
```

```tsx tab="src/components/mdx.tsx"
import defaultMdxComponents from "fumadocs-ui/mdx";
import { Callout } from "fumadocs-ui/components/callout";
import type { MDXComponents } from "mdx/types";

export default { ...defaultMdxComponents, Callout } satisfies MDXComponents;
```

Relative links in `a` resolve to page URLs automatically. Components such as `Tabs`, `Steps` and `Files` are not registered by default; import them in the MDX file or add them to your components module.
