## Overview

A content source is a [Fumadocs source](https://fumadocs.dev/docs/headless/source-api) passed to `createPress`. Fumadocs MDX pages render without setup. Other sources come with a plugin that renders their pages through the [content hooks](#content-hooks).

<DocsCategory />

## Usage

Pass the source to `createPress` and add its plugin:

```tsx title="press.config.tsx"
import { createPress } from "fumapress";
import { createNotion } from "@fumadocs/notion";
import notionPlugin from "@fumadocs/notion/press";
import { Client } from "@notionhq/client";

const notion = createNotion({
  client: new Client({ auth: process.env.NOTION_TOKEN }),
  dataSourceId: process.env.NOTION_DATA_SOURCE_ID!,
});

export default createPress(notion.dynamicSource({ properties: { title: "Name", slug: "Slug" } }), {
  loaderOptions: { alwaysRevalidate: true },
})
  .plugins(notionPlugin({ notion }))
  .config({ mode: "dynamic" });
```

You can pass multiple sources as a record. The keys become `page.type` and `props.type`:

```tsx title="press.config.tsx"
export const app = createPress({
  docs: docs.toFumadocsSource({ baseDir: "docs" }),
  blog: blog.toFumadocsSource({ baseDir: "blog" }),
});
```

## Content Hooks

A content source's plugin renders pages by implementing these hooks on `Plugin`. Each hook receives a page and returns its data, or `undefined` for pages it does not own.

### `getPageBody`

Returns `{ node }` with the rendered React content of the page.

### `getPageText`

Returns the plain text of the page, used by search and LLM exports.

### `getPageToc`

Returns the table of contents entries.

### `getPageStructuredData`

Returns structured data for the search index.

### `getPageCreatedAt`

Returns the creation date of the page.

### `getPageLastModified`

Returns the last modified date of the page.

A minimal content hook plugin:

```tsx title="acme/index.tsx"
import type { AppShape, Plugin } from "@fumapress/core";

interface AcmePageData {
  load: () => Promise<string>;
  plainText: () => string;
}

function isAcmePage(data: object): data is AcmePageData {
  return "load" in data && "plainText" in data;
}

export default function acmePlugin<C extends AppShape = AppShape>(): Plugin<C> {
  return {
    name: "acme",
    async getPageBody(page) {
      if (!isAcmePage(page.data)) return;
      return { node: <div>{await page.data.load()}</div> };
    },
    getPageText(page) {
      if (isAcmePage(page.data)) return page.data.plainText();
    },
  };
}
```

See the [Fumadocs MDX](/docs/adapters/mdx), [Notion](/docs/adapters/notion), [Sanity](/docs/adapters/sanity) and [Obsidian](/docs/adapters/obsidian) pages for complete implementations.
