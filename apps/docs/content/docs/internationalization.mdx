## Setup

Pass an i18n config to `createPress`:

```tsx title="press.config.tsx"
import { createPress } from "fumapress";
import { defineDocs } from "fumadocs-mdx/macro";
import { defineI18n } from "fumadocs-core/i18n";
import { zhTW } from "@fumapress/language/zh-tw";

const docs = defineDocs({
  dir: "content/docs",
  docs: { async: true },
});

const i18n = defineI18n({
  languages: ["en", "zh"],
  defaultLanguage: "en",
});

export const app = createPress({ docs: docs.toFumadocsSource() }, { i18n });

export default app.config({
  ui: {
    translations: i18n.translations().preset("zh", zhTW()),
  },
});
```

## Translations

`i18n.translations()` creates the translations config. Use `.preset()` with a [language pack](#using-language-packs) to add all strings for a language, or `.add()` for individual keys:

```tsx title="press.config.tsx"
import { zhTW } from "@fumapress/language/zh-tw";

export default app.config({
  ui: {
    translations: i18n
      .translations()
      .preset("zh", zhTW())
      .add({
        en: { displayName: "English" },
        zh: {
          displayName: "Chinese",
          "Search(search dialog)": "搜尋文檔",
          "Blog(blog)": "博客",
          "All Tags(blog tags page)": "全部标签",
        },
      }),
  },
});
```

Plugins bring their own translations.

### Using Language Packs

The official language pack adds translations for Fumapress and its integrations.

```npm
npm i @fumapress/language
```

```tsx title="press.config.tsx"
import { zhTW } from "@fumapress/language/zh-tw";

const translations = i18n.translations().preset("zh", zhTW());
```

Available presets:

- `zhCN` from `@fumapress/language/zh-cn`
- `zhTW` from `@fumapress/language/zh-tw`

### Writing Content

Add Markdown/JSON files for different languages by appending `.{locale}` to your file name:

<Files>
  <Folder name="content" defaultOpen>

    <File name="meta.zh.json" />

    <File name="get-started.zh.mdx" />

### Fallback Pages

Locales without a translation of a page inherit the file of the [fallback language](https://fumadocs.dev/docs/headless/internationalization/config#fallback-language), so `/zh/get-started` exists even when only `get-started.mdx` does. Inherited pages are served but not advertised: they get `noindex` with a canonical link to the source page, and the sitemap, RSS feed, `llms-full.txt` and Takumi images skip them.

## Routing

Every language is served under its own URL prefix, and `page.url` includes it. To drop the prefix of the default language, set `hideLocale`:

```tsx title="press.config.tsx"
const i18n = defineI18n({
  languages: ["en", "zh"],
  defaultLanguage: "en",
  hideLocale: "default-locale",
});
```

| Source                     | `hideLocale: "never"` (default) | `hideLocale: "default-locale"` |
| -------------------------- | ------------------------------- | ------------------------------ |
| `content/docs/index.mdx`   | `/en`, `/zh`                    | `/`, `/zh`                     |
| `content/docs/setup.mdx`   | `/en/setup`, `/zh/setup`        | `/setup`, `/zh/setup`          |
| `src/pages/about.tsx`      | `/en/about`, `/zh/about`        | `/about`, `/zh/about`          |
| Blog index (plugin routes) | `/en/blog`, `/zh/blog`          | `/blog`, `/zh/blog`            |
| Not found page             | `/404`, in the URL's language   | `/404`, in the URL's language  |
| `/`                        | redirects to `/en`              | the index page of `en`         |

Without a page at `/en`, like with content under a `baseDir`, `/` and the navbar title go to the first page of `en` instead.

Set `site.hreflang` to map language codes that are not BCP 47 tags:

```tsx title="press.config.tsx"
export default app.config({
  site: { hreflang: { zh: "zh-Hant" } },
  // ...
});
```

### File-based Pages

Waku only. Pages and layouts in `src/pages` are registered once per language, under its prefix. `WakuRouteProps<typeof app>` gives the `lang` prop:

```tsx title="src/pages/about.tsx"
import type { WakuRouteProps } from "fumapress";
import type { app } from "../../press.config";

export default function Page({ lang }: WakuRouteProps<typeof app>) {
  return <h1>{lang === "zh" ? "关于" : "About"}</h1>;
}
```

With `autoI18n: false`, a page is registered once at its own path and rendered as the default language. See [Routing](/docs/routing#file-based-routing) for route config.

### In Plugins and Layouts

Build language-aware links with `this.localizePath()` from the site context. It adds the prefix unless `hideLocale` hides it:

```tsx title="src/layout.tsx"
import type { UIOptions } from "fumapress";
import type { app } from "../press.config";

export const baseOptions: UIOptions<typeof app>["baseOptions"] = function ({ lang }) {
  return {
    links: [{ url: this.localizePath(lang, "/blog"), text: lang === "zh" ? "部落格" : "Blog" }],
  };
};
```

Views are registered once per language automatically and linked as translations. See [Views](/docs/plugins/authoring#views).
