### Components per Page

List the MDX renderer yourself, with `components` as a function of the page. It replaces the renderer that `press()` builds from your module:

```tsx title="press.config.tsx"
import mdxPlugin from "fumadocs-mdx/press";
import components from "./src/components/mdx";
import { Mermaid } from "./src/components/mermaid";

createPress(content).plugins(
  mdxPlugin({
    components: (page) =>
      page.path.startsWith("guides/") ? { ...components, Mermaid } : components,
  }),
);
```

`page` has the types of your content. The plugins of the [Notion, Sanity and Obsidian sources](/docs/content-sources) take `components` as a function too.

### Image Optimization

Markdown images and `Image` are optimized when your platform supports image optimization. Without `site.baseUrl`, the self-hosted provider leaves images as they are.

| Platform   | Provider                                                                                              | Needs                                |
| ---------- | ----------------------------------------------------------------------------------------------------- | ------------------------------------ |
| Vercel     | [Vercel Image Optimization](https://vercel.com/docs/image-optimization)                               | nothing                              |
| Cloudflare | [Image Transformations](https://developers.cloudflare.com/images/transform-images/transform-via-url/) | transformations enabled on your zone |
| Node.js    | Self-hosted, with [Sharp](https://sharp.pixelplumbing.com)                                            | `sharp`, a server and `site.baseUrl` |

### Remote Images

Local paths are always allowed. For remote images, pass `image: false` to `recommendedPreset()` and add the provider with its options:

<Tabs items={["Vercel", "Cloudflare", "Self-hosted"]}>
<Tab value="Vercel">

```tsx title="press.config.tsx"
import { createPress, recommendedPreset } from "fumapress";
import { vercelImage } from "fumapress/plugins/image/vercel";

export const app = createPress(content).plugins(vercelImage({ domains: ["github.com"] }));

export default app.config({ preset: recommendedPreset({ image: false }) });
```

### Disabling Optimization

On a static host with `sharp` installed, turn off image optimization, since the self-hosted provider needs a server:

```tsx title="press.config.tsx"
import { createPress, recommendedPreset } from "fumapress";

export default createPress(content).config({
  preset: recommendedPreset({ image: false }),
});
```

For another optimizer, see [Replacing a Default Plugin](/docs/plugins#replacing-a-default-plugin).
