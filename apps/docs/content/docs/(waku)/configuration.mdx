`press.config.tsx` at the project root configures your site. Only `createPress()` is required.

```tsx title="press.config.tsx"
import { createPress } from "fumapress";
import { rssPlugin } from "fumapress/plugins/rss";

export const app = createPress(content, { i18n }).plugins(rssPlugin());

export default app.config({
  site: { name: "Acme" },
  head: [{ tag: "link", attrs: { rel: "icon", href: "/favicon.ico" } }],
  ui: { baseOptions, renderPage },
});
```

### URL

Set the URL of your deployed site, with its base path if there is one. Without it, canonical links, the sitemap, RSS and Open Graph images fall back to relative URLs.

```tsx title="press.config.tsx"
createPress(content).config({
  site: {
    baseUrl: "https://docs.example.com",
  },
});
```

### Root Document

`ui.renderRoot` replaces the `<html>` document, for example to add a class to `<html>` or `<body>`:

```tsx title="press.config.tsx"
createPress(content).config({
  ui: {
    renderRoot({ lang, head, children }) {
      return (
        <html lang={lang ?? "en"} className="dark" suppressHydrationWarning>
          <head>{head}</head>
          <body className="antialiased">{children}</body>
        </html>
      );
    },
  },
});
```

## Build and Dev Server

`press.config.tsx` doesn't configure the build or the dev server. Use these instead.

### Vite Plugin

`press()` takes these options:

```ts title="vite.config.ts"
import { defineConfig } from "vite";
import tailwindcss from "@tailwindcss/vite";
import press from "fumapress/vite";
import { fumadocsMdx } from "fumadocs-mdx/vite";

const components = "./src/components/mdx.tsx";

export default defineConfig({
  plugins: [press({ components }), fumadocsMdx(), tailwindcss()],
});
```

### CLI

Run the site through `fumapress` instead of `vite`.

```json title="package.json"
{
  "scripts": {
    "dev": "fumapress dev",
    "build": "fumapress build",
    "start": "fumapress start"
  }
}
```

`dev` listens on port 3000, and `start` uses the first free port from 8080. To choose, set `PORT` and `HOST` or pass a flag:

```npm
npm run dev -- --port 4000 --host 0.0.0.0
```

### Environment Variables

The CLI loads `.env`, `.env.local` and mode variants like `.env.production`. Variables already set in the environment take priority.

- **Server code and `press.config.tsx`**: any variable, through `process.env`.
- **Client code**: only variables prefixed with `VITE_`, through `import.meta.env`.

Files that only the server can read, like key files, go in the `private` directory. Change it with the `privateDir` option of `press()`.

## Server Entry

Most sites don't need one. Create it to pass [Waku adapter options](/docs/deployment#deploying-without-a-function) or to define routes in code.

### Install Waku [step]

Install the version that Fumapress uses:

```npm
npm i waku@1.0.0-rc.1
```

### Create the Entry [step]

```tsx title="src/waku.server.tsx"
import _adapter from "waku/adapters/default";
import press from "../press.config";
import { createRouter } from "fumapress/router";
import { fsRouterFn } from "fumapress/router/fs";

const router = await createRouter(press);
import.meta.hot?.dispose(router.dispose);

const modules = import.meta.glob("./pages/**/*.{ts,tsx,js,jsx}", {
  base: "/src",
});

const pages = router.createPages(fsRouterFn(modules));
const middlewareFns = router.createMiddlewares();
const adapter = router.patchAdapter(_adapter);

export default adapter(pages, { middlewareFns });
```

### Config-Based Routing

To use [config-based routing](https://waku.gg/#routing) instead of `src/pages`, pass a callback to `createPages()`. Don't create a root element, since Fumapress already creates one.

```tsx title="src/waku.server.tsx"
// [!code --]
const pages = router.createPages(fsRouterFn(modules));
// [!code ++:9]
const pages = router.createPages(({ createPage }) => {
  createPage({
    render: "static",
    path: "/hello-world",
    component() {
      return <main>Hello World</main>;
    },
  });
});
```

## Types

Export the result of `.plugins()` as `app`, and pass `typeof app` to the type helpers from `fumapress`:

```tsx title="src/ui/layout.tsx"
import type { RenderPageProps } from "fumapress";
import type { app } from "../../press.config";

export function renderPage(props: RenderPageProps<typeof app>) {
  // ...
}
```

| Helper            | For                                                            |
| ----------------- | -------------------------------------------------------------- |
| `RenderPageProps` | props of `ui.renderPage`, narrowed to a source or plugin page  |
| `UIOptions`       | an option of `ui`, like `UIOptions<typeof app>["baseOptions"]` |
| `PressContext`    | `this` in callbacks, the result of `getPressContext()`         |
| `WakuRouteProps`  | props of custom pages                                          |
| `WakuRouteConfig` | the result of `getConfig()`                                    |
| `BaseOptions`     | the Fumadocs layout props                                      |
| `ProviderProps`   | the root provider props                                        |
