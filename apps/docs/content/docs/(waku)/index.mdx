Fumapress turns your Markdown files into a complete docs site on [Waku](https://waku.gg). It is built on [Fumadocs](https://fumadocs.dev) and comes with layouts, search, SEO files and plugins. Custom pages and layouts are React Server Components.

## Create a Site

### Create the Project [step]

```npm
npm create fumapress -- --framework waku
```

### Start the Dev Server [step]

From the new folder:

```npm
npm run dev
```

The project looks like this:

```files
├── content
│   └── index.mdx
├── src
│   └── app.css
├── press.config.tsx
└── vite.config.ts
```

### Name the Site [step]

Set the name in `press.config.tsx`. It shows in the navbar and page metadata.

```tsx title="press.config.tsx"
export default createPress(docs.toFumadocsSource()).config({
  site: {
    name: "My Docs", // [!code highlight]
  },
});
```
