## Search Engines

FlexSearch is the default, and `search` of `recommendedPreset()` takes its options, like in [Customization](#customization). To use another engine, set `search: false` and add the plugin of the engine. Without one, the site has no search:

```tsx tab="Orama" title="press.config.tsx"
import { createPress, recommendedPreset } from "fumapress";
import { oramaSearchPlugin } from "fumapress/plugins/orama-search";

export const app = createPress(content).plugins(oramaSearchPlugin());

export default app.config({
  preset: recommendedPreset({ search: false }),
});
```

```tsx tab="None" title="press.config.tsx"
import { createPress, recommendedPreset } from "fumapress";

createPress(content).config({
  preset: recommendedPreset({ search: false }),
});
```

An engine like Algolia is a separate plugin. See [Custom Search Engine](/docs/plugins/authoring#custom-search-engine).
