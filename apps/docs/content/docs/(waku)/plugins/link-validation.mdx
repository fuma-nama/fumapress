---
title: Link Validation
description: Find broken links at build time.
---

<include cwd>content/shared/plugins/link-validation.mdx#intro</include>

Add the plugin:

```tsx title="press.config.tsx"
import { linkValidationPlugin } from "fumapress/plugins/link-validation";

createPress(content).plugins(linkValidationPlugin());
```

It checks links in Fumadocs layouts and your content. On custom pages, use `Link` from `fumapress/client`, since a plain `<a>` isn't tracked.
