## llms.txt

<include cwd>content/shared/plugins/ai.mdx#llms-intro</include>

Add the plugin to pass options. It replaces the default one:

```tsx title="press.config.tsx"
import { llmsPlugin } from "fumapress/plugins/llms.txt";

createPress(content).plugins(llmsPlugin());
```

<Callout type="warn">
  Keep [`includeProcessedMarkdown`](/docs/content-sources/fumadocs-mdx#setup) on your Fumadocs MDX
  collection. This plugin reads the text of pages from the processed Markdown.
</Callout>

### Custom Pages

Set `routes: "all"`, then return Markdown from a page with `asMarkdown()` and `md`. This page gets a `/index.md`, and an entry in `/llms.txt`.

```tsx tab="src/pages/index.tsx"
import { asMarkdown, md } from "fumapress/markdown";

export default function Page() {
  if (asMarkdown()) {
    return md`
# My Site

Welcome! Read the [docs](/docs).
    `;
  }

  return <main>...</main>;
}
```

```tsx tab="press.config.tsx"
llmsPlugin({ routes: "all" });
```

<Callout type="warn">
  The Markdown renders without your layouts, so an access check in a layout doesn't cover it. Put the check in the page, or in middleware that also covers `<page>.md`.
</Callout>

Only server components that call `asMarkdown()` are converted to Markdown. Other components stay as JSX in the output, like `<Card title="...">...</Card>`. To give a client component a Markdown version, wrap it in a server component:

```tsx
import { asMarkdown, md } from "fumapress/markdown";

function Callout({ title, children }) {
  if (asMarkdown()) return md.linePrefix("> ")`**${title}**\n${children}`;

  return <div className="callout">...</div>;
}
```

`md` also has `md.indent(size)`. To render a React tree to Markdown yourself, use `renderToMarkdown(<Page />)`.

### Custom Layout

The default layout docks the chat for you. With a custom [`renderPage`](/docs/layouts#rendering-pages), place the action and dock the chat yourself. Wrap `DocsLayout` in a client component:

```tsx tab="src/chat-layout.tsx"
"use client";
import { DocsLayout, type DocsLayoutProps } from "fumadocs-ui/layouts/docs";
import { AIChatPanel, useAIChat } from "@fumapress/ai/components/chat";

export function ChatLayout(props: DocsLayoutProps) {
  const { open, setOpen } = useAIChat();

  const aiChat = { open, onOpenChange: setOpen, panel: <AIChatPanel /> };

  return <DocsLayout {...props} aiChat={aiChat} />;
}
```

```tsx tab="src/ui/layout.tsx"
import { DocsBody, DocsPage, DocsTitle } from "fumadocs-ui/layouts/docs/page";
import { ChatLayout } from "../chat-layout";

function Docs({ baseOptions, tree, pageData, body, actions }: RenderPageProps<typeof app, "docs">) {
  return (
    <ChatLayout {...baseOptions} tree={tree}>
      <DocsPage toc={pageData.toc}>
        <div className="flex justify-end">{actions.ai}</div>
        <DocsTitle>{pageData.title}</DocsTitle>
        <DocsBody>{body}</DocsBody>
      </DocsPage>
    </ChatLayout>
  );
}
```
