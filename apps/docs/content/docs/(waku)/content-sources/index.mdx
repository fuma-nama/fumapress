## Multiple Sources

Pass an object to use multiple sources on one site. Each key names a source, and `baseDir` is its URL prefix.

```tsx title="press.config.tsx"
// [!code word:baseDir]
export default createPress({
  docs: docs.toFumadocsSource({ baseDir: "docs" }),
  guides: notion.dynamicSource({ baseDir: "guides" }),
}).plugins(notionPlugin({ notion }));
```

Now your MDX pages are under `/docs`, and the Notion pages are under `/guides`. Use the key `"guides"` to give those pages [their own layout](/docs/layouts#layout-per-source).
