![Notebook Layout](/layouts/notebook.webp)

See [Fumadocs Notebook Layout](https://fumadocs.dev/docs/ui/layouts/notebook) for the available props.

Swap the imports of the Docs Layout for `fumadocs-ui/layouts/notebook` and `fumadocs-ui/layouts/notebook/page`:

```tsx title="src/ui/layout.tsx"
import { selectTreeRoot, type RenderPageProps } from "fumapress";
import { DocsLayout } from "fumadocs-ui/layouts/notebook";
import { DocsBody, DocsPage, DocsTitle } from "fumadocs-ui/layouts/notebook/page";
import type { app } from "../../press.config";

export function Notebook({
  tree,
  baseOptions,
  pageData,
  body,
}: RenderPageProps<typeof app, "docs">) {
  return (
    <DocsLayout {...baseOptions} tree={selectTreeRoot(tree, "docs")}>
      <DocsPage toc={pageData.toc} full={pageData.full}>
        <DocsTitle>{pageData.title}</DocsTitle>
        <DocsBody>{body}</DocsBody>
      </DocsPage>
    </DocsLayout>
  );
}
```

It takes the same page data and slots as the [Docs Layout](/docs/layouts/docs).
