![Notebook Layout](/layouts/notebook.webp)

See [Fumadocs Notebook Layout](https://fumadocs.dev/docs/ui/layouts/notebook) for the available props.

On Astro, render `DocsLayout` of `fumadocs-ui/layouts/notebook` in your [page module](/docs/astro/layouts#page-module).

```tsx title="press.config.tsx"
import { defineConfig } from "fumapress";
import { createNotebookLayoutPage } from "fumapress/layouts/notebook";

const NotebookLayout = createNotebookLayoutPage<typeof config.$context>();

const config = defineConfig({
  // ...
  renderPage: (props) => <NotebookLayout {...props} />,
});

export default config;
```

It accepts the same [options](/docs/layouts/docs#options) as the docs layout.
