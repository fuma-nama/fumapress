See [Fumadocs Docs Layout](https://fumadocs.dev/docs/ui/layouts/docs) and [Docs Page](https://fumadocs.dev/docs/ui/layouts/page) for the available props.

The built-in UI (`renderDefault()`) uses this layout for content pages. To customize it, compose `DocsLayout` and `DocsPage` from `fumadocs-ui/layouts/docs` and `fumadocs-ui/layouts/docs/page` with `pageData`:

```tsx title="src/ui/layout.tsx"
import { selectTreeRoot, type RenderPageProps } from "fumapress";
import { DocsLayout } from "fumadocs-ui/layouts/docs";
import {
  DocsBody,
  DocsDescription,
  DocsPage,
  DocsTitle,
  MarkdownCopyButton,
  ViewOptionsPopover,
} from "fumadocs-ui/layouts/docs/page";
import type { app } from "../../press.config";

export function Docs({
  tree,
  baseOptions,
  pageData,
  body,
  actions,
}: RenderPageProps<typeof app, "docs">) {
  return (
    <DocsLayout {...baseOptions} tree={selectTreeRoot(tree, "docs")}>
      <DocsPage toc={pageData.toc} full={pageData.full}>
        <DocsTitle>{pageData.title}</DocsTitle>
        <DocsDescription>{pageData.description}</DocsDescription>
        <div className="flex gap-2">
          {pageData.markdownUrl && <MarkdownCopyButton markdownUrl={pageData.markdownUrl} />}
          <ViewOptionsPopover markdownUrl={pageData.markdownUrl} githubUrl={pageData.githubUrl} />
          {Object.values(actions)}
        </div>
        <DocsBody>{body}</DocsBody>
      </DocsPage>
    </DocsLayout>
  );
}
```

## Page Data

`pageData` is available on every content page:

- `title`: the page title.
- `description`: the page description.
- `toc`: the table of contents entries.
- `full`: whether the page uses the full width.
- `lastModified`: the last modified date, when enabled on the content source.
- `markdownUrl`: the URL to its Markdown content, for LLMs.
- `githubUrl`: the URL to view its source file, when `site.git` is configured.
- `url`: the URL of the page.

## Sidebar

`selectTreeRoot(tree, "docs")` scopes the sidebar to the `docs` folder of the page tree. Pass the `baseDir` of a [content collection](/docs/collections). Nested paths like `"docs/guides"` work too. It throws listing the available folders when the path does not match.

```tsx
import { selectTreeRoot } from "fumapress";

<DocsLayout {...baseOptions} tree={selectTreeRoot(tree, "docs")}>
```

## Page Actions

The page area between the title and the body is where actions go: `MarkdownCopyButton`, `ViewOptionsPopover`, and plugin actions like `actions.ai`. See [Page Actions and Footers](/docs/layouts#page-actions-and-footers).
