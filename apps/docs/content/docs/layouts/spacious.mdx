---
title: Spacious Layout
description: The docs layout with the page in an inset panel.
---

![Spacious Layout](/layouts/spacious.webp)

See [Fumadocs Spacious Layout](https://fumadocs.dev/docs/ui/layouts/spacious) for the available props.

Requires Fumadocs UI v16.16.0 or above (`@fumadocs/base-ui`). Its styles are not in the Fumadocs UI preset. Import them:

```css title="src/app.css"
@import "tailwindcss";
/* [!code ++] */
@import "fumadocs-ui/css/generated/spacious.css";
@import "fumadocs-ui/css/neutral.css";
@import "fumadocs-ui/css/preset.css";
@import "fumapress/css/preset.css";
```

Swap the imports of the Docs Layout for `fumadocs-ui/layouts/spacious` and `fumadocs-ui/layouts/spacious/page`:

```tsx title="src/ui/layout.tsx"
import { selectTreeRoot, type RenderPageProps } from "fumapress";
import { DocsLayout } from "fumadocs-ui/layouts/spacious";
import { DocsBody, DocsPage, DocsTitle } from "fumadocs-ui/layouts/spacious/page";
import type { app } from "../../press.config";

export function Spacious({
  tree,
  baseOptions,
  pageData,
  body,
}: RenderPageProps<typeof app, "docs">) {
  return (
    <DocsLayout {...baseOptions} tree={selectTreeRoot(tree, "docs")}>
      <DocsPage toc={pageData.toc} full={pageData.full}>
        <DocsTitle>{pageData.title}</DocsTitle>
        <DocsBody>{body}</DocsBody>
      </DocsPage>
    </DocsLayout>
  );
}
```

It takes the same page data and slots as the [Docs Layout](/docs/layouts/docs). The [AI plugin](/docs/plugins/ai) docks its chat beside the page on wide screens.

<Callout title="Important to know">

- The spacious layout is a client component. The layout's props cannot contain unserializable values (functions) unless they are supported slots.
- On desktop, the page scrolls inside the panel instead of the window.

</Callout>
