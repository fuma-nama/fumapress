## Overview

Use the spacious layout for docs pages that should keep docs features, but use the spacious appearance from Fumadocs UI: a less compact docs layout, where the page sits in an inset panel beside the sidebar, with page-level actions at the top of the panel.

It requires the Base UI version of Fumadocs UI (`@fumadocs/base-ui`) v16.16.0 or above.

## Setup

Like the glass layout, spacious layout styles are not bundled into the Fumadocs UI CSS preset. Import them in `src/app.css`:

```css title="src/app.css"
@import "tailwindcss";
/* [!code ++] */
@import "fumadocs-ui/css/generated/spacious.css";
@import "fumadocs-ui/css/neutral.css";
@import "fumadocs-ui/css/preset.css";
@import "fumapress/css/preset.css";
```

## Config

Define the layout and pass it through `renderPage`.

```tsx title="press.config.tsx"
import { defineConfig } from "fumapress";
import { createSpaciousLayoutPage } from "fumapress/layouts/spacious";

const SpaciousLayout = createSpaciousLayoutPage<typeof config.$context>();

const config = defineConfig({
  // ...
  renderPage: (props) => <SpaciousLayout {...props} />,
});

export default config;
```

The spacious layout accepts the same kind of `render` option as the docs layout:

```tsx title="press.config.tsx"
import { defineConfig } from "fumapress";
import { createSpaciousLayoutPage } from "fumapress/layouts/spacious";

const SpaciousLayout = createSpaciousLayoutPage<typeof config.$context>({
  async render(page) {
    return {
      pageProps: {
        full: true,
      },
    };
  },
});

const config = defineConfig({
  // ...
  renderPage: (props) => <SpaciousLayout {...props} />,
});

export default config;
```

The `render` function can return page props, layout props, markdown URL, last modified date, or a custom body.

Other options, such as `treeRoot` and interceptors, work the same as in the [docs layout](/docs/layouts/docs#options).

<Callout title="Important to know">

- The spacious layout is a client component, you cannot pass unserializable values (e.g. functions) in `layoutProps` unless they are supported slots.
- On desktop, the page scrolls inside the panel instead of the window.

</Callout>

## AI Chat

The [AI plugin](/docs/plugins/ai) integrates with the spacious layout natively: the Ask AI trigger is shown at the top of the page panel, and the chat is docked beside the page on wide screens, using its `aiChat` option.
