---
title: Glass Layout
description: The docs layout with floating, translucent sidebar and header.
---

![Glass Layout](/layouts/glass.webp)

See [Fumadocs Glass Layout](https://fumadocs.dev/docs/ui/layouts/glass) for the available props.

Requires Fumadocs UI v16.12.0 or above. Its styles are not in the Fumadocs UI preset. Import them:

```css title="src/app.css"
@import "tailwindcss";
/* [!code ++] */
@import "fumadocs-ui/css/generated/glass.css";
@import "fumadocs-ui/css/neutral.css";
@import "fumadocs-ui/css/preset.css";
@import "fumapress/css/preset.css";
```

Swap the imports of the Docs Layout for `fumadocs-ui/layouts/glass` and `fumadocs-ui/layouts/glass/page`:

```tsx title="src/ui/layout.tsx"
import { selectTreeRoot, type RenderPageProps } from "fumapress";
import { DocsLayout } from "fumadocs-ui/layouts/glass";
import { DocsBody, DocsPage, DocsTitle } from "fumadocs-ui/layouts/glass/page";
import type { app } from "../../press.config";

export function Glass({ tree, baseOptions, pageData, body }: RenderPageProps<typeof app, "docs">) {
  return (
    <DocsLayout {...baseOptions} tree={selectTreeRoot(tree, "docs")}>
      <DocsPage toc={pageData.toc} full={pageData.full}>
        <DocsTitle>{pageData.title}</DocsTitle>
        <DocsBody>{body}</DocsBody>
      </DocsPage>
    </DocsLayout>
  );
}
```

It takes the same page data and slots as the [Docs Layout](/docs/layouts/docs). The [AI plugin](/docs/plugins/ai) shows its Ask AI trigger in the header and sidebar.

<Callout title="Important to know">

The glass layout is a client component. The layout's props cannot contain unserializable values (functions) unless they are supported slots.

</Callout>
