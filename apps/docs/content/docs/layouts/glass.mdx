---
title: Glass Layout
description: The docs layout with floating, translucent sidebar and header.
---

![Glass Layout](/layouts/glass.webp)

See [Fumadocs Glass Layout](https://fumadocs.dev/docs/ui/layouts/glass) for the available props.

Requires Fumadocs UI v16.12.0 or above. Its styles are not in the Fumadocs UI preset, import them:

```css title="src/app.css"
@import "tailwindcss";
/* [!code ++] */
@import "fumadocs-ui/css/generated/glass.css";
@import "fumadocs-ui/css/neutral.css";
@import "fumadocs-ui/css/preset.css";
@import "fumapress/css/preset.css";
```

```tsx title="press.config.tsx"
import { defineConfig } from "fumapress";
import { createGlassLayoutPage } from "fumapress/layouts/glass";

const GlassLayout = createGlassLayoutPage<typeof config.$context>();

const config = defineConfig({
  // ...
  renderPage: (props) => <GlassLayout {...props} />,
});

export default config;
```

It accepts the same [options](/docs/layouts/docs#options) as the docs layout, and the [AI plugin](/docs/plugins/ai) shows its Ask AI trigger in the header and sidebar.

<Callout title="Important to know">

The glass layout is a client component, `layoutProps` cannot contain unserializable values (e.g. functions) unless they are supported slots.

</Callout>
