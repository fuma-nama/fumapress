## Installation

This plugin is included in `fumapress`.

Set [`site.baseUrl`](/docs/config#site) in your config. Sitemap entries must be fully-qualified URLs:

```tsx title="press.config.tsx"
import { createPress } from "fumapress";
// [!code ++]
import { sitemapPlugin } from "fumapress/plugins/sitemap";

export default createPress(content)
  // [!code ++]
  .plugins(sitemapPlugin())
  .config({
    site: {
      // [!code highlight]
      baseUrl: "https://example.com",
    },
  });
```

The plugin creates a sitemap at `/sitemap.xml`.

By default, every page from your content source is included with a `priority` of `0.8`, and static routes are included as well.

## Options

### `path`

Change the sitemap route. Default: `"/sitemap.xml"`.

```tsx title="press.config.tsx"
sitemapPlugin({
  path: "/sitemap.xml",
});
```

### `getEntry`

Customize or exclude entries. Return `undefined` to omit a page:

```tsx title="press.config.tsx"
sitemapPlugin({
  async getEntry(page) {
    if (page.path.startsWith("drafts/")) return;

    return {
      loc: this.absoluteUrl(page.url),
      lastmod: page.data.lastModified,
      changefreq: "weekly",
      priority: page.path === "index" ? 1 : 0.8,
      alternates: await this.getPageAlternates(page),
    };
  },
});
```

`getEntry` receives the site context as `this`, so you can call `absoluteUrl()`, `getPageAlternates()` and other [context members](/docs/plugins/authoring). Each alternate item carries a `lang` field for its `hreflang`.

Each entry supports the standard sitemap fields (`loc`, `lastmod`, `changefreq`, `priority`), plus the Google extensions:

- `alternates`: alternate language versions of the page, written as `xhtml:link` hreflang elements. `this.getPageAlternates(page)` returns the translations of a page.
- `images`: images on the page ([image extension](https://developers.google.com/search/docs/crawling-indexing/sitemaps/image-sitemaps)).
- `videos`: videos on the page ([video extension](https://developers.google.com/search/docs/crawling-indexing/sitemaps/video-sitemaps)).
- `news`: news article metadata ([Google News extension](https://developers.google.com/search/docs/crawling-indexing/sitemaps/news-sitemap)), at most one per URL.

An entry with a video looks like:

```tsx
{
  loc: "https://example.com/videos/intro",
  videos: [
    {
      thumbnail_loc: "https://example.com/thumbs/intro.jpg",
      title: "Introducing Fumapress",
      description: "A quick tour of the framework.",
      content_loc: "https://example.com/videos/intro.mp4",
    },
  ],
}
```

### `additionalEntries`

Append extra URLs that are not backed by content pages. Each entry's `loc` must be a fully-qualified
URL:

```tsx title="press.config.tsx"
sitemapPlugin({
  additionalEntries: [
    {
      loc: "https://example.com/changelog",
      changefreq: "weekly",
      priority: 0.5,
    },
  ],
});
```

Pass a function to compute entries at build time:

```tsx title="press.config.tsx"
sitemapPlugin({
  additionalEntries() {
    return [
      {
        loc: this.absoluteUrl("/rss.xml"),
        changefreq: "daily",
      },
    ];
  },
});
```

## Custom Sitemaps

For additional sitemaps, the `buildSitemap` function serializes entries to XML. Serve it from an [API route](/docs/plugins/authoring#api-routes) of a plugin in your config, like a [custom RSS feed](/docs/plugins/rss#custom-feeds).
