## Installation

```npm
npm i @fumapress/blog
```

Import the CSS preset:

```css title="src/app.css"
@import "tailwindcss";
@import "fumadocs-ui/css/neutral.css";
@import "fumadocs-ui/css/preset.css";
@import "fumapress/css/preset.css";
/* [!code ++] */
@import "@fumapress/blog/css/preset.css";
```

### Fumadocs MDX

Create a blog collection with the blog schemas and add the plugin. The `source` option is required and names the content source key whose pages are posts:

```tsx title="press.config.tsx"
import { createPress } from "fumapress";
import { defineDocs } from "fumadocs-mdx/macro";
// [!code ++]
import { blogPlugin } from "@fumapress/blog";
// [!code ++]
import { blogPageSchema } from "@fumapress/blog/schema";

const docs = defineDocs({ dir: "content/docs" });

// [!code ++:5]
const blog = defineDocs({
  dir: "content/blog",
  docs: { schema: blogPageSchema },
});

export default createPress({
  docs: docs.toFumadocsSource(),
  // [!code ++]
  blog: blog.toFumadocsSource({ baseDir: "blog" }),
})
  // [!code ++]
  .plugins(blogPlugin({ source: "blog" }))
  .config({/* ... */});
```

Write blog posts under the `content/blog` directory:

```mdx title="content/blog/hello-world.mdx"
---
title: My Blog Post
description: Hello World!!!
date: 2026-09-06
tags: [my-tag]
---

## Introduction

Welcome to my first blog post.
```

`blogPageSchema` supports the following frontmatter fields:

| Field         | Description                                        |
| ------------- | -------------------------------------------------- |
| `title`       | The post title (required)                          |
| `description` | Shown below the title and on post cards            |
| `date`        | Publish date, the order of posts                   |
| `tags`        | Post tags. Each tag gets a page under `/blog/tags` |
| `authors`     | Author ids. See the [`authors`](#authors) option   |
| `image`       | Cover image URL, shown on post cards               |

Cover images and author avatars render through the [`Image`](/docs/plugins/image) component. Remote URLs need their hostname allowed by the image plugin:

```tsx tab="Self-hosted" title="press.config.tsx"
import { selfHostedImage } from "fumapress/plugins/image/self-hosted";

selfHostedImage({ allowedHosts: ["avatars.githubusercontent.com"] });
```

```tsx tab="Vercel" title="press.config.tsx"
import { vercelImage } from "fumapress/plugins/image/vercel";

vercelImage({ domains: ["avatars.githubusercontent.com"] });
```

<Callout type="warn" title="Watch for redirects">
  A redirect that leaves the origin is checked again, so allow the final host too.
  `github.com/<user>.png`, for example, redirects to `avatars.githubusercontent.com`.
</Callout>

### Other Content Sources

Without Fumadocs MDX, pass your content source and the options that resolve post data. The date comes from the page creation date (`getPageCreatedAt`). Tags, authors and image can be resolved with `getTags`, `getAuthors` and `getImage`:

```tsx title="press.config.tsx"
blogPlugin({
  source: "blog",
  getTags(page) {
    return page.data.tags;
  },
  getAuthors(page) {
    return page.data.authors;
  },
  getImage(page) {
    return page.data.image;
  },
});
```

To use several content sources as posts, pass an array:

```tsx title="press.config.tsx"
blogPlugin({
  source: ["blog", "news"],
  getTags: (page) => page.data.tags ?? [page.type],
});
```

## Options

### `paths`

Override the pathnames of the blog pages. Set a path to `false` to disable it:

```tsx title="press.config.tsx"
blogPlugin({
  source: "blog",
  paths: {
    index: "/blog",
    tags: "/blog/tags",
  },
});
```

### `authors`

Register authors once, keyed by the ids used in the `authors` frontmatter of posts:

```tsx title="press.config.tsx"
blogPlugin({
  source: "blog",
  authors: {
    fuma: {
      name: "Fuma Nama",
      title: "Maintainer",
      url: "https://fuma-nama.dev",
      image: "https://github.com/fuma-nama.png",
    },
  },
});
```

```mdx title="content/blog/hello-world.mdx"
---
title: My Blog Post
authors: [fuma]
---
```

Ids missing from the registry are shown by name only.

## Custom UI

The plugin renders four [views](/docs/plugins/authoring#views): `blog` (a post), `blog.index` (the post list), `blog.tags` (tag list) and `blog.tag` (posts of one tag). Replace or compose them as [`renderPage`](/docs/layouts#render-page) cases.

Replace the index with your own UI from the typed `props.posts`, and compose the post view with `BlogPostView`:

```tsx title="press.config.tsx"
import { createPress } from "fumapress";
import { blogPlugin, BlogPostView } from "@fumapress/blog";
import { blogPageSchema } from "@fumapress/blog/schema";
import { defineDocs } from "fumadocs-mdx/macro";
import { HomeLayout } from "fumadocs-ui/layouts/home";

const blog = defineDocs({ dir: "content/blog", docs: { schema: blogPageSchema } });

export const app = createPress({
  blog: blog.toFumadocsSource({ baseDir: "blog" }),
}).plugins(blogPlugin({ source: "blog" }));

export default app.config({
  ui: {
    renderPage(props) {
      const { renderDefault } = props;
      switch (props.type) {
        case "blog.index":
          return (
            <HomeLayout {...props.baseOptions}>
              <ul>
                {props.posts.map((post) => (
                  <li key={post.page.url}>
                    {post.page.data.title} {post.page.data.tags?.join(", ")}
                  </li>
                ))}
              </ul>
            </HomeLayout>
          );
        case "blog":
          return (
            <HomeLayout {...props.baseOptions}>
              <BlogPostView post={props.post} newer={props.newer} older={props.older}>
                {props.body}
              </BlogPostView>
            </HomeLayout>
          );
        default:
          return renderDefault();
      }
    },
  },
});
```

The view components `BlogPostView`, `BlogIndexView`, `BlogTagsView` and `BlogTagView` are exported from `@fumapress/blog`.

## Posts in Your Pages

`getBlogPosts(ctx, { lang })` returns all posts newest first. Use it in your own pages, like a landing page:

```tsx title="src/pages/index.tsx"
import { getPressContext } from "fumapress";
import { getBlogPosts } from "@fumapress/blog";
import { Link } from "fumapress/client";
import type { app } from "../../press.config";

export default async function Home() {
  const posts = await getBlogPosts(getPressContext<typeof app>());
  return (
    <main>
      <h1>Acme</h1>
      <ul>
        {posts.slice(0, 3).map((post) => (
          <li key={post.page.url}>
            <Link href={post.page.url}>{post.page.data.title}</Link>
            {post.date && (
              <time dateTime={post.date.toISOString()}>{post.date.toDateString()}</time>
            )}
            {post.authors.map((author) => author.name).join(", ")}
          </li>
        ))}
      </ul>
    </main>
  );
}
```

Each `post` carries `page`, `date`, `authors` and `tags`. Tag links use `tag.url`:

```tsx
{
  post.tags.map((tag) => (
    <a key={tag.tag} href={tag.url}>
      {tag.tag}
    </a>
  ));
}
```
