## Overview

Plugins add features to your site. Pass them to `.plugins()` on `createPress`:

```tsx title="press.config.tsx"
import { createPress } from "fumapress";
import { defineDocs } from "fumadocs-mdx/macro";
import { llmsPlugin } from "fumapress/plugins/llms.txt";

const docs = defineDocs({ dir: "content/docs" });

export default createPress({ docs: docs.toFumadocsSource() })
  // [!code ++]
  .plugins(llmsPlugin())
  .config({});
```

Lists are flattened and falsy values skipped, so plugins can be conditional:

```tsx title="press.config.tsx"
.plugins(
  process.env.ENABLE_BLOG && blogPlugin({ source: "blog" }),
)
```

Every plugin runs on both Waku and Astro unless its page says otherwise.

## Capabilities

A capability is a feature only one plugin provides. The built-in capabilities are `search`, `sitemap`, `robots`, `llms`, `rss`, `og-image`, `image` and `ai-chat`. A second plugin providing the same capability is an error naming both.

Listing a plugin that provides a capability replaces the [preset](/docs/config#preset) entry for that capability. For example, adding `llmsPlugin()` with options replaces the default llms.txt entry:

```tsx title="press.config.tsx"
import { createPress } from "fumapress";
import { llmsPlugin } from "fumapress/plugins/llms.txt";
import { takumiPlugin } from "fumapress/plugins/takumi";

// ...

export default createPress(content)
  .plugins(
    llmsPlugin({ getLLMText: async (page) => `# ${page.data.title}` }),
    takumiPlugin({ width: 1600, height: 840 }),
  )
  .config({});
```

To drop a preset entry entirely, filter it out:

```tsx title="press.config.tsx"
import { createPress, recommendedPreset } from "fumapress";

// ...

export default createPress(content).config({
  preset: recommendedPreset().filter((entry) => entry.provides !== "rss"),
});
```

## Order

Your plugins run first, in list order. The [preset](/docs/config#preset) entries that no listed plugin replaced come next. The runtime's defaults come last.

Middleware nests in the same order: the first plugin in your list wraps the second, which wraps the preset's, and so on.

```tsx title="press.config.tsx"
import { createPress, type AppShape, type Plugin } from "fumapress";
import { defineDocs } from "fumadocs-mdx/macro";
import { mintlifyPlugin } from "@fumapress/mintlify";

function guardPlugin<C extends AppShape = AppShape>(options: {
  prefix: string;
  token: string;
}): Plugin<C> {
  return {
    name: "acme:guard",
    async middleware(request, next) {
      const { pathname } = new URL(request.url);
      if (
        pathname.startsWith(this.withBase(options.prefix)) &&
        request.headers.get("authorization") !== `Bearer ${options.token}`
      )
        return new Response("Unauthorized", { status: 401 });
      return next();
    },
  };
}

const docs = defineDocs({ dir: "content/docs" });

export default createPress({ docs: docs.toFumadocsSource() })
  .plugins(
    guardPlugin({ prefix: "/internal", token: process.env.DOCS_TOKEN ?? "" }),
    mintlifyPlugin(),
  )
  .config({ mode: "dynamic" });
```

Plugin base options merge under yours. Links concatenate:

```tsx title="press.config.tsx"
import { createPress } from "fumapress";
import { mintlifyPlugin } from "@fumapress/mintlify";

// ...

export default createPress(content)
  .plugins(mintlifyPlugin(), {
    name: "site:links",
    baseOptions: () => ({ links: [{ url: "/blog", text: "Blog" }] }),
  })
  .config({ ui: { baseOptions: { nav: { title: "Acme" } } } });
```

## Inline Plugins

A plugin object written in your config handles site-only hooks without a separate module. Use it for a `layout.wrapper` analytics provider or a nav link:

```tsx title="press.config.tsx"
import { createPress } from "fumapress";
import { defineDocs } from "fumadocs-mdx/macro";
import { Analytics } from "./src/analytics";

const docs = defineDocs({ dir: "content/docs" });

export default createPress({ docs: docs.toFumadocsSource() })
  .plugins({
    name: "site:analytics",
    slots: ({ page }) =>
      page ? undefined : [{ slot: "layout.wrapper", component: Analytics, props: { id: "a1" } }],
  })
  .config({});
```

Misspelled hooks are type errors.
