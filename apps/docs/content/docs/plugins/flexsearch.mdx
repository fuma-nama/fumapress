## Installation

This plugin is included in `fumapress` and enabled by default through the [recommended preset](/docs/config#preset). It creates a search API at `/api/search` and enables the search dialog.

In static mode, the search index is generated as static data, downloaded by the dialog and searched in the browser. See [Search](/docs/search) for the overall search setup.

Add it explicitly to customize options:

```tsx title="press.config.tsx"
import { createPress } from "fumapress";
// [!code ++]
import { flexsearchPlugin } from "fumapress/plugins/flexsearch";

export default createPress(docs.toFumadocsSource())
  // [!code ++]
  .plugins(flexsearchPlugin())
  .config({ site: { name: "Acme" } });
```

Listing it takes the place of the preset's default. Two search plugins are an error naming both.

## Options

### `buildIndex`

Customize the index fields. `this` is the site context. By default, the plugin uses structured data from the content source.

```tsx title="press.config.tsx"
flexsearchPlugin({
  buildIndex(page) {
    return {
      id: page.url,
      title: page.data.title,
      description: page.data.description,
      url: page.url,
      structuredData: page.data.structuredData,
      tag: page.path.split("/")[0],
    };
  },
});
```

The returned index must include `structuredData`. If your content source does not expose structured data, provide it from your own page data.

The engine options of Fumadocs [`flexsearchFromSource`](https://fumadocs.dev/docs/headless/search/flexsearch) are passed through.
