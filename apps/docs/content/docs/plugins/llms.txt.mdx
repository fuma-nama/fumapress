title: llms.txt
description: Expose your documentation as LLM-friendly text files.
---

## Installation

This plugin is included in `fumapress`.

Enable the plugin:

```tsx title="press.config.tsx"
import { createPress } from "fumapress";
// [!code ++]
import { llmsPlugin } from "fumapress/plugins/llms.txt";

export default createPress(content)
  // [!code ++]
  .plugins(llmsPlugin())
  .config({/* ... */});
```

The plugin creates:

- `/llms.txt`: an index of your documentation pages.
- `/llms-full.txt`: a combined text export of all pages.
- `/*.md`: a Markdown version for each page.

It also adds the Markdown URL to docs pages, so layouts can show a "Copy Markdown" link when supported.

### Fumadocs MDX

To include the processed Markdown of pages (after remark/rehype), enable `postprocess.includeProcessedMarkdown`:

```tsx title="press.config.tsx"
const docs = defineDocs({
  dir: "content/docs",
  docs: { postprocess: { includeProcessedMarkdown: true } },
});
```

Without it, pages use their source files.

## Options

### `getLLMText`

Controls how each page appears in `/llms-full.txt`. Return `undefined` to exclude a page:

```tsx title="press.config.tsx"
llmsPlugin({
  getLLMText(page) {
    return `# ${page.data.title} (${this.absoluteUrl(page.url)})

${page.data.description ?? ""}`;
  },
});
```

### `routes`

By default, only pages of your content source get a Markdown version. With `routes: "all"`, every page route with a Markdown form gets `<page>.md` and an llms.txt entry. Your own pages define their Markdown with [`fumapress/markdown`](/docs/markdown):

```tsx title="press.config.tsx"
llmsPlugin({ routes: "all" });
```

```tsx title="src/pages/index.tsx"
import { asMarkdown, md } from "fumapress/markdown";

export default function Page() {
  if (asMarkdown()) {
    return md`
# My Site

Welcome! Read the [docs](/docs).
    `;
  }

  return <main>...</main>;
}
```

### `autoRedirect`

When a request prefers Markdown in its `Accept` header (for example, from an AI agent), the plugin serves the page's Markdown version at the original URL. Enabled by default; ignored in static mode since it requires a server:

```tsx title="press.config.tsx"
llmsPlugin({ autoRedirect: false });
```
