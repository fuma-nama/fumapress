## Installation

```npm
npm i fumadocs-openapi shiki
```

Configure the plugin:

```tsx title="press.config.tsx"
import { defineConfig } from "fumapress";
import { docs } from "./.source/server";
// [!code ++:3]
import path from "node:path";
import { createOpenAPI } from "fumadocs-openapi/server";
import { openapiPlugin } from "fumapress/plugins/openapi";

// [!code ++:4]
const openapi = createOpenAPI({
  // path or URL to your OpenAPI spec
  input: [path.resolve("./openapi.json")],
});

export default defineConfig({
  content: {
    docs: docs.toFumadocsSource(),
    // [!code ++]
    openapi: await openapi.staticSource(),
  },
})
  // fumapress plugin [!code ++]
  .plugins(openapiPlugin({ server: openapi }));
```

Update the path/URL to your OpenAPI spec (e.g. `./openapi.json`), the API pages will be automatically generated based on your spec.

## Options

You can see [Fumadocs OpenAPI](https://www.fumadocs.dev/docs/integrations/openapi) for details of advanced options.

### `openapi.staticSource()`

It support a subset of options from [`generateFiles()`](https://www.fumadocs.dev/docs/integrations/openapi/generate-files).

<Callout title="How to customize its output file structure?">

It accepts a `baseDir` option. For example, the following will generate all API pages under the `(openapi)` folder:

```tsx title="press.config.tsx"
import { defineConfig } from "fumapress";
import { docs } from "./.source/server";

export default defineConfig({
  content: {
    docs: docs.toFumadocsSource(),
    openapi: await openapi.staticSource({
      // [!code highlight]
      baseDir: "(openapi)",
    }),
  },
});
```

</Callout>

### Client UI

Create the renderer for API pages explicitly:

```tsx title="src/components/api.tsx"
"use client";
import { createClientAPIPage } from "fumadocs-openapi/ui/create-client";

export const ClientAPIPage = createClientAPIPage();
```

And import it from the OpenAPI plugin:

```tsx title="press.config.tsx"
// [!code ++]
import { ClientAPIPage } from "./src/components/api";

export default defineConfig({
  // ...
}).plugins(
  openapiPlugin({
    server: openapi,
    // [!code ++]
    ClientAPIPage,
  }),
);
```

### Proxy Server

To create the [Proxy Server](https://fumadocs.dev/docs/integrations/openapi/server#creating-proxy), define `proxyUrl` in `createOpenAPI()` options:

```tsx title="press.config.tsx"
import { defineConfig } from "fumapress";
import { createOpenAPI } from "fumadocs-openapi/server";
import { openapiPlugin } from "fumapress/plugins/openapi";

const openapi = createOpenAPI({
  // [!code ++]
  proxyUrl: "/_proxy",
});

export default defineConfig({
  // ...
}).plugins(
  openapiPlugin({
    server: openapi,
  }),
);
```
