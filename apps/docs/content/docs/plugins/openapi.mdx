## Installation

```npm
npm i fumadocs-openapi shiki
```

Import the CSS preset:

```css title="src/app.css"
@import "tailwindcss";
@import "fumadocs-ui/css/neutral.css";
@import "fumadocs-ui/css/preset.css";
@import "fumapress/css/preset.css";
/* [!code ++] */
@import "fumadocs-openapi/css/preset.css";
```

Configure the plugin:

```tsx title="press.config.tsx"
import { createPress } from "fumapress";
import { defineDocs } from "fumadocs-mdx/macro";
// [!code ++:2]
import { createOpenAPI } from "fumadocs-openapi/server";
import openapiPlugin from "fumadocs-openapi/press";

const docs = defineDocs({ dir: "content/docs" });

// [!code ++:4]
const openapi = createOpenAPI({
  // path or URL to your OpenAPI spec
  input: ["./openapi.yaml"],
});

export default createPress({
  docs: docs.toFumadocsSource(),
  // [!code ++]
  openapi: await openapi.staticSource({ baseDir: "docs/api" }),
})
  // [!code ++]
  .plugins(openapiPlugin({ server: openapi }))
  .config({/* ... */});
```

Update the path to your OpenAPI spec. API pages are generated from the spec.

## Options

See [Fumadocs OpenAPI](https://www.fumadocs.dev/docs/integrations/openapi) for details of advanced options.

### `openapi.staticSource()`

It supports a subset of options from [`generateFiles()`](https://www.fumadocs.dev/docs/integrations/openapi/generate-files).

<Callout title="How to customize its output file structure?">

It accepts a `baseDir` option. For example, the following generates all API pages under the `(openapi)` folder:

```tsx title="press.config.tsx"
openapi.staticSource({
  baseDir: "(openapi)",
});
```

</Callout>

### Client UI

Create the renderer for API pages explicitly:

```tsx title="src/components/openapi.tsx"
"use client";
import { createOpenAPIPage } from "fumadocs-openapi/ui";

export const OpenAPIPage = createOpenAPIPage();
```

And import it from the OpenAPI plugin:

```tsx title="press.config.tsx"
import { OpenAPIPage } from "./src/components/openapi";

openapiPlugin({
  server: openapi,
  // [!code ++]
  ClientAPIPage: OpenAPIPage,
});
```

### Proxy Server

To create the [Proxy Server](https://fumadocs.dev/docs/integrations/openapi/server#creating-proxy), define `proxyUrl` in `createOpenAPI()` and pass `createProxy` to the plugin:

```tsx title="press.config.tsx"
import { createOpenAPI } from "fumadocs-openapi/server";
import openapiPlugin from "fumadocs-openapi/press";

const openapi = createOpenAPI({
  input: ["./openapi.yaml"],
  // [!code ++]
  proxyUrl: "/_proxy",
});

openapiPlugin({
  server: openapi,
  // [!code ++:4]
  createProxy: {
    allowedOrigins: ["https://example.com"],
  },
});
```

Pass `createProxy: true` to enable the proxy without restricting origins.

<Callout type="warn" title="Security">

Always set `allowedOrigins` to the API hosts you trust. The proxy forwards headers and body from the playground, including cookies and `Authorization`. An open proxy can be abused to call arbitrary origins.

</Callout>
