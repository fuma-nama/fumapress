## Installation

```npm
npm i @fumapress/ai
```

Add the plugin,
it requires a `model` option, set this to an AI model you prefer (e.g. GPT).

```npm
npm i @ai-sdk/openai
```

```tsx title="press.config.tsx"
import { defineConfig } from "fumapress";
import { openai } from "@ai-sdk/openai";
// [!code ++]
import { aiPlugin } from "@fumapress/ai";

export default defineConfig({
  // ...
})
  // [!code highlight:5]
  .plugins(
    aiPlugin({
      model: openai("gpt-5"),
    }),
  );
```

See [AI SDK](https://ai-sdk.dev/docs/foundations/providers-and-models) docs for all available models.

Finally, initialize the `src/app.css` file and add the following:

```css title="src/app.css"
@import "tailwindcss";
@import "fumadocs-ui/css/neutral.css";
@import "fumadocs-ui/css/preset.css";
@import "fumapress/css/preset.css";
/* [!code ++] */
@import "@fumapress/ai/css/preset.css";
```
