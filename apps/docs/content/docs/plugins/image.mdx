title: Image Optimization
description: Optimize images under different viewports.
---

Waku only.

## Installation

This plugin is included in `fumapress` and enabled by default through the [recommended preset](/docs/config#preset), with a provider matching your deployment target (detected from the environment like the deployment adapter):

- **Vercel**: uses [Vercel Image Optimization](https://vercel.com/docs/image-optimization). Works with static mode.
- **Cloudflare**: uses [Cloudflare Image Transformations](https://developers.cloudflare.com/images/transform-images/transform-via-url/) via `/cdn-cgi/image/`. Works with static mode when your zone has transformations enabled.
- **Self-hosted** (Node.js): runs a dynamic optimization endpoint powered by [Sharp](https://sharp.pixelplumbing.com/). Requires Sharp to be installed:

```npm
npm i sharp
```

On other targets, or when the requirements above are not met, image optimization is skipped and the `Image` component renders a plain `<img>`.

To customize options, list the provider explicitly. It takes the place of the preset's:

```tsx tab="Vercel" title="press.config.tsx"
import { createPress } from "fumapress";
// [!code ++]
import { vercelImage } from "fumapress/plugins/image/vercel";

export default createPress(docs.toFumadocsSource())
  // [!code ++]
  .plugins(vercelImage({ domains: ["github.com"] }))
  .config({ site: { name: "Acme" } });
```

```tsx tab="Cloudflare" title="press.config.tsx"
import { createPress } from "fumapress";
// [!code ++]
import { cloudflareImage } from "fumapress/plugins/image/cloudflare";

export default createPress(docs.toFumadocsSource())
  // [!code ++]
  .plugins(cloudflareImage({ format: "auto", fit: "scale-down" }))
  .config({ site: { name: "Acme" } });
```

```tsx tab="Self-hosted" title="press.config.tsx"
import { createPress } from "fumapress";
// [!code ++]
import { selfHostedImage } from "fumapress/plugins/image/self-hosted";

export default createPress(docs.toFumadocsSource())
  // [!code ++]
  .plugins(selfHostedImage({ path: "/_img", allowedHosts: ["github.com"] }))
  .config({ mode: "dynamic" });
```

To turn off image optimization, filter the preset entry:

```tsx title="press.config.tsx"
import { createPress, recommendedPreset } from "fumapress";

export default createPress(docs.toFumadocsSource()).config({
  preset: recommendedPreset().filter((entry) => entry.provides !== "image"),
});
```

## Usage

Use the `Image` component from `fumapress/image`.

```tsx
import { Image } from "fumapress/image";

export default function Hero() {
  return <Image src="/hero.png" alt="Hero" width={1200} height={630} className="rounded-lg" />;
}
```

When image optimization is enabled, it generates responsive `srcSet` values and serves optimized formats automatically. Remote images must be explicitly allowed (self-hosted), match your Vercel image configuration, or be permitted in your Cloudflare zone's transformation settings. Local paths such as `/logo.png` are always allowed.

Props specific to the component:

- `quality`: compression quality from 1 to 100, defaults to the provider's default.
- `sizes`: the standard [`sizes`](https://developer.mozilla.org/en-US/docs/Web/API/HTMLImageElement/sizes) attribute, also used to decide the generated `srcSet` widths.
- `preload`: emit a preload hint for the image, defaults to `true`. Disable it for below-the-fold images.
- `unoptimized`: serve the image as-is. SVG images are not optimized by default.

## Custom Providers

A third-party image optimizer is a `WakuPlugin` with `provides: ["image"]`. Its client provider wraps every layout as a `layout.wrapper` slot:

```tsx tab="provider.tsx"
"use client";
import type { ReactNode } from "react";

export function CloudinaryProvider({ cloud, children }: { cloud: string; children?: ReactNode }) {
  return <div data-cloud={cloud}>{children}</div>;
}
```

```tsx tab="press.config.tsx"
import { createPress, type WakuAppShape, type WakuPlugin } from "fumapress";
import { CloudinaryProvider } from "./src/provider";

function cloudinaryImage<C extends WakuAppShape = WakuAppShape>(options: {
  cloud: string;
}): WakuPlugin<C, { provides: "image" }> {
  return {
    name: "cloudinary:image",
    provides: ["image"],
    slots: ({ page }) =>
      page
        ? undefined
        : [
            {
              slot: "layout.wrapper",
              component: CloudinaryProvider,
              props: { cloud: options.cloud },
              order: -10,
            },
          ],
  };
}

export default createPress(docs.toFumadocsSource())
  .plugins(cloudinaryImage({ cloud: "acme" }))
  .config({});
```

See [Capabilities](/docs/plugins/authoring#capabilities) for declaring what a plugin provides.
