## Installation

This plugin is included in `fumapress` and enabled by default through the [recommended preset](/docs/config#preset). Add it yourself to configure it:

```tsx title="press.config.tsx"
import { createPress } from "fumapress";
// [!code ++]
import { takumiPlugin } from "fumapress/plugins/takumi";

export default createPress(docs.toFumadocsSource())
  // [!code ++]
  .plugins(takumiPlugin())
  .config({ site: { name: "Acme" } });
```

The plugin creates a `.webp` Open Graph image for every content page with [Takumi](https://takumi.kane.tw), and adds the matching metadata:

```html
<meta property="og:image" content="/docs/page.webp" />
<meta property="og:image:width" content="1200" />
<meta property="og:image:height" content="630" />
<meta property="twitter:card" content="summary_large_image" />
```

The default image shows the page title, description, and site name.

<Callout type='warn'>

Set `site.baseUrl` in your config to make `og:image` resolve to an absolute URL.

```tsx title="press.config.tsx"
export default createPress(docs.toFumadocsSource()).config({
  site: {
    // [!code ++]
    baseUrl: "https://press.fumadocs.dev",
  },
});
```

</Callout>

## Options

### `getImage`

Customize the image of a page. `this` is the site context:

```tsx title="press.config.tsx"
takumiPlugin({
  getImage(page) {
    return {
      node: (
        <div
          style={{
            width: "100%",
            height: "100%",
            display: "flex",
            flexDirection: "column",
            justifyContent: "center",
            padding: 80,
            background: "#111",
            color: "white",
          }}
        >
          <p>{this.siteConfig.name}</p>
          <h1>{page.data.title}</h1>
        </div>
      ),
      options: { quality: 80 },
    };
  },
});
```

### `path`

The base route for generated images. Defaults to `/` in static mode and `/_takumi` in dynamic mode.

### `options`

Image response options shared by every image. The ones returned from `getImage()` override them per page.

Values resolved once belong here. `googleFonts()` downloads the font files on every call, so create the promise at module scope instead of inside `getImage()`:

```tsx title="press.config.tsx"
import { googleFonts, takumiPlugin } from "fumapress/plugins/takumi";

const fonts = googleFonts([{ name: "Geist", weight: [500, 800] }]);

takumiPlugin({
  options: { fonts },
});
```

`fontFromUrl()` does the same for a self-hosted font file. `fumapress/plugins/takumi` re-exports both from the `takumi-js` copy the plugin renders with.

### `width` / `height`

The image dimensions, defaulting to `1200x630`. They are applied to the rendered image and the `og:image` meta tags. The response format is always `webp`.

```tsx title="press.config.tsx"
takumiPlugin({ width: 1600, height: 840 });
```

## Route Images

Waku only. Pages in `src/pages` get an image from `ogImage` in their route config:

```tsx title="src/pages/pricing.tsx"
import type { WakuRouteConfig } from "fumapress";

export function getConfig() {
  return { render: "static", ogImage: { title: "Pricing" } } satisfies WakuRouteConfig;
}
```

The image is prerendered as `/pricing.webp` with the default template, and the page receives the same `og:image` meta tags as a content page. Pass `node` to draw it yourself, and `options` for the image response options of this route.

For routes with slugs, a function receives the route params:

```tsx title="src/pages/showcase/[slug].tsx"
import type { WakuRouteConfig } from "fumapress";

export function getConfig() {
  return {
    render: "static",
    staticPaths: Object.keys(items),
    ogImage(params) {
      const item = items[params.slug as string];
      return { title: item?.title, description: item?.description };
    },
  } satisfies WakuRouteConfig;
}
```

A static page gets a prerendered `.webp` file next to it, one per entry of `staticPaths`. A dynamic page renders its image on request from an image route under `/_takumi`.

## WebAssembly

Waku only. Takumi renders with its native Rust addon on Node.js and Bun, and with WebAssembly on other runtimes. When the machine building your site cannot load the native addon, like Cloudflare Workers Builds, pass the WebAssembly build instead:

```tsx title="press.config.tsx"
import { takumiPlugin } from "fumapress/plugins/takumi";
// [!code ++]
import wasm from "fumapress/plugins/takumi.wasm";

takumiPlugin({
  options: {
    // [!code ++]
    module: wasm,
  },
});
```

The binary is only bundled when you import it.
