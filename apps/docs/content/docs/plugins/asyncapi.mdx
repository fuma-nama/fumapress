## Installation

```npm
npm i @fumadocs/asyncapi shiki
```

Import the CSS preset:

```css title="src/app.css"
@import "tailwindcss";
@import "fumadocs-ui/css/neutral.css";
@import "fumadocs-ui/css/preset.css";
@import "fumapress/css/preset.css";
/* [!code ++] */
@import "@fumadocs/asyncapi/css/preset.css";
```

Configure the plugin:

```tsx title="press.config.tsx"
import { createPress } from "fumapress";
import { defineDocs } from "fumadocs-mdx/macro";
// [!code ++:2]
import { createAsyncAPI } from "@fumadocs/asyncapi/server";
import asyncapiPlugin from "@fumadocs/asyncapi/press";

const docs = defineDocs({ dir: "content/docs" });

// [!code ++:4]
const asyncapi = createAsyncAPI({
  // path or URL to your AsyncAPI spec
  input: ["./asyncapi.yaml"],
});

export default createPress({
  docs: docs.toFumadocsSource(),
  // [!code ++]
  asyncapi: await asyncapi.staticSource({ baseDir: "docs/events" }),
})
  // [!code ++]
  .plugins(asyncapiPlugin({ server: asyncapi }))
  .config({/* ... */});
```

Update the path to your AsyncAPI spec. API pages are generated from the spec.

## Options

See [Fumadocs AsyncAPI](https://www.fumadocs.dev/docs/integrations/asyncapi) for details of advanced options.

### `asyncapi.staticSource()`

It supports a subset of options from [`generateFiles()`](https://www.fumadocs.dev/docs/integrations/asyncapi/generate-files).

<Callout title="How to customize its output file structure?">

It accepts a `baseDir` option. For example, the following generates all API pages under the `(asyncapi)` folder:

```tsx title="press.config.tsx"
asyncapi.staticSource({
  baseDir: "(asyncapi)",
});
```

</Callout>

### Client UI

Create the renderer for API pages explicitly:

```tsx title="src/components/asyncapi.tsx"
"use client";
import { createAsyncAPIPage } from "@fumadocs/asyncapi/ui";

export const AsyncAPIPage = createAsyncAPIPage();
```

And import it from the AsyncAPI plugin:

```tsx title="press.config.tsx"
import { AsyncAPIPage } from "./src/components/asyncapi";

asyncapiPlugin({
  server: asyncapi,
  // [!code ++]
  ClientAPIPage: AsyncAPIPage,
});
```
