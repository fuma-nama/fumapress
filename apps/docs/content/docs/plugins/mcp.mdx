## Installation

The MCP plugin is included in `@fumapress/ai`.

```npm
npm i @fumapress/ai
```

Add the plugin:

```tsx title="press.config.tsx"
import { createPress } from "fumapress";
// [!code ++]
import { mcpPlugin } from "@fumapress/ai";

export default createPress(content)
  // [!code ++]
  .plugins(mcpPlugin())
  .config({/* ... */});
```

The plugin creates an MCP server at `/mcp` using the [Streamable HTTP](https://modelcontextprotocol.io/specification/2025-03-26/basic/transports#streamable-http) transport. The server needs a runtime with request handling, so it is not compatible with `mode: "static"`.

If `this` in the plugin's options needs typing outside `.plugins()`, use `Plugin` from `fumapress`:

```ts
import type { Plugin } from "fumapress";
import { mcpPlugin } from "@fumapress/ai";

export const mcp: Plugin = mcpPlugin({
  tools(server) {
    // `this` is the site context
  },
});
```

## Connect MCP Clients

Point your MCP client at the server URL. For local development, that is usually `http://localhost:3000/mcp`.

In production, use your site URL with the configured path (for example, `https://press.fumadocs.dev/mcp`).

## Built-in Tools

The plugin registers three tools on the MCP server:

| Tool         | Description                                                                       |
| ------------ | --------------------------------------------------------------------------------- |
| `search`     | Full-text search over your documentation. Returns matching pages as JSON.         |
| `get_page`   | Fetch the content of a page by its URL (for example, `/docs/getting-started`).    |
| `list_pages` | Return the `llms.txt` index of all documentation pages, with the URL of each one. |

When i18n is configured, the `search` tool accepts a `locale` parameter to filter results by language.

## Options

### `path`

Change the MCP endpoint path:

```tsx title="press.config.tsx"
mcpPlugin({
  path: "/api/mcp",
});
```

### `server`

Customize MCP server metadata. The server name defaults to `site.name`:

```tsx title="press.config.tsx"
mcpPlugin({
  server: {
    name: "My Docs",
    version: "2.0.0",
  },
});
```

### `pageToIndex`

Controls how pages are indexed for search and page retrieval. Return `null` to exclude a page:

```tsx title="press.config.tsx"
mcpPlugin({
  pageToIndex(page) {
    return {
      title: page.data.title ?? "",
      description: page.data.description ?? "",
      url: page.url,
      content: page.data.description ?? "",
      locale: page.locale ?? "",
    };
  },
});
```

### `tools`

Register additional tools on the MCP server, an `McpServer` of [`@modelcontextprotocol/server`](https://www.npmjs.com/package/@modelcontextprotocol/server) v2:

```tsx title="press.config.tsx"
import { mcpPlugin } from "@fumapress/ai";
import { z } from "zod";

mcpPlugin({
  tools(server) {
    server.registerTool(
      "get_site_name",
      {
        title: "Get Site Name",
        description: "Return the site name from the config",
        inputSchema: z.object({}),
      },
      async () => ({
        content: [{ type: "text", text: this.siteConfig.name }],
      }),
    );
  },
});
```
