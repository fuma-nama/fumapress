## Installation

```npm
npm i @fumadocs/graphql
```

Import the CSS preset:

```css title="src/app.css"
@import "tailwindcss";
@import "fumadocs-ui/css/neutral.css";
@import "fumadocs-ui/css/preset.css";
@import "fumapress/css/preset.css";
/* [!code ++] */
@import "@fumadocs/graphql/css/preset.css";
```

Configure the plugin:

```tsx title="press.config.tsx"
import { createPress } from "fumapress";
// [!code ++:2]
import { createGraphQL } from "@fumadocs/graphql/server";
import graphqlPlugin from "@fumadocs/graphql/press";

// [!code ++:4]
const graphql = createGraphQL({
  // SDL files/URLs, SDL text, introspection results, or `GraphQLSchema` instances
  input: ["./schema.graphql"],
});

export default createPress({
  // [!code ++]
  graphql: await graphql.staticSource({ baseDir: "docs/graphql" }),
})
  // [!code ++]
  .plugins(graphqlPlugin({ server: graphql }))
  .config({/* ... */});
```

It generates a page per operation (query/mutation/subscription) and named type by default, grouped into folders by their kind (for example, `queries/`, `objects/`).

## Options

See [Fumadocs GraphQL](https://www.fumadocs.dev/docs/integrations/graphql) for details of advanced options.

### `graphql.staticSource()`

<Callout title="How to customize its output file structure?">

It accepts a `baseDir` option. For example, the following generates all pages under the `(graphql)` folder:

```tsx title="press.config.tsx"
graphql.staticSource({
  baseDir: "(graphql)",
});
```

</Callout>

### Client UI

Create the renderer for GraphQL pages explicitly. This allows you to enable the interactive playground on operation pages:

```tsx title="src/components/graphql.tsx"
"use client";
import { createGraphQLPage } from "@fumadocs/graphql/ui";

export const GraphQLPage = createGraphQLPage({
  playground: {
    // the URL of your GraphQL endpoint (optional)
    url: "https://api.example.com/graphql",
  },
});
```

And import it from the GraphQL plugin:

```tsx title="press.config.tsx"
import { GraphQLPage } from "./src/components/graphql";

graphqlPlugin({
  server: graphql,
  // [!code ++]
  ClientAPIPage: GraphQLPage,
});
```

<Callout title="Using i18n?">

Links pre-generated from the schema are not localized. Use the `typeLinks` and `operationLinks` options of `createGraphQLPage()` to resolve links yourself.

</Callout>
