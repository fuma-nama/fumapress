## Installation

This plugin is included in `fumapress`.

Enable the plugin in your Fumapress config, it replaces the default FlexSearch from the [recommended preset](/docs/config#preset):

```tsx title="press.config.tsx"
import { defineConfig } from "fumapress";
// [!code ++]
import { oramaSearchPlugin } from "fumapress/plugins/orama-search";

export default defineConfig({
  // ...
})
  // [!code ++]
  .plugins(oramaSearchPlugin());
```

The plugin creates a search API at `/api/search` and enables the search dialog in the docs provider.
In static mode, the search index is generated as static data.

Every language works out of the box, including Chinese, Japanese and Korean: the default `multilingual` tokenizer splits text on Unicode word boundaries, and i18n sites share one index filtered by locale.
You don't need `localeMap`, `@orama/*` packages or a custom search dialog.

## Options

### `buildIndex`

By default, the plugin uses structured data from your configured adapters.
Define `buildIndex` to customize the index fields:

```tsx title="press.config.tsx"
import { defineConfig } from "fumapress";
import { oramaSearchPlugin } from "fumapress/plugins/orama-search";

export default defineConfig({
  // ...
}).plugins(
  oramaSearchPlugin({
    buildIndex(page) {
      return {
        id: page.url,
        title: page.data.title,
        description: page.data.description,
        url: page.url,
        structuredData: page.data.structuredData,
        tag: page.path.split("/")[0],
      };
    },
  }),
);
```

The returned index must include `structuredData`. If your content source does not expose structured data,
add it with a content adapter or provide it from your own page data.

### `tokenizer`

The `multilingual` tokenizer applies no stemming, so a query for `recordings` won't match a page that only says `recording`.
Attach a stemmer while keeping multilingual segmentation:

```npm
npm install @zbsearch/stemmers
```

```tsx title="press.config.tsx"
import { defineConfig } from "fumapress";
import { oramaSearchPlugin } from "fumapress/plugins/orama-search";
// [!code ++]
import { stemmer } from "@zbsearch/stemmers/english";

export default defineConfig({
  // ...
}).plugins(
  oramaSearchPlugin({
    // [!code ++]
    tokenizer: { language: "multilingual", stemming: true, stemmer },
  }),
);
```

<Callout type="warn" title="Static mode">
  The browser restores the tokenizer language from the exported index, not a custom stemmer, so
  queries would no longer match the stemmed index. Keep `tokenizer` for the `default` and `dynamic`
  [render modes](/docs/config#render-mode).
</Callout>
