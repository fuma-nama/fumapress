## Update Packages

```npm
npm i fumapress@latest fumadocs-core@latest fumadocs-mdx@latest
```

`fumadocs-core` 16.18.0 and `fumadocs-mdx` 15.5.0 or later are required. If you use the blog, install it:

```npm
npm i @fumapress/blog
```

## press.config

`defineConfig()` is refactored into three stages: `createPress(content, options).plugins(...).config({...})`.

```tsx title="press.config.tsx"
// [!code --:8]
import { defineConfig } from "fumapress";
import { fumadocsMdx } from "fumapress/adapters/mdx";

export default defineConfig({
  content: docs.toFumadocsSource(),
  loaderOptions: { plugins: [lucideIconsPlugin()] },
  site: { name: "My Docs" },
})
  .adapters(fumadocsMdx())
  .plugins(llmsPlugin());
// [!code ++:8]
import { createPress } from "fumapress";

export const app = createPress(docs.toFumadocsSource(), {
  loaderOptions: { plugins: [lucideIconsPlugin()] },
}).plugins(llmsPlugin());

export default app.config({ site: { name: "My Docs" } });
```

| Before                                                    | After                                                                     |
| --------------------------------------------------------- | ------------------------------------------------------------------------- |
| `defineConfig({ content, loaderOptions, i18n, ...rest })` | `createPress(content, { loaderOptions, i18n }).plugins(...).config(rest)` |
| `typeof config.$context`                                  | `typeof app` (the `.plugins()` result)                                    |
| `config.utils().getPressContext()`                        | `getPressContext<typeof app>()`                                           |
| `.adapters(fumadocsMdx({ getMdxComponents }))`            | `press({ components })` in `vite.config.ts`                               |

### MDX Components

The MDX adapter is refactored into the Vite plugin. Move your components into a module and pass it to `press()`:

```ts tab="vite.config.ts"
import press from "fumapress/vite";

export default defineConfig({
  plugins: [
    // [!code ++]
    press({ components: "./src/components/mdx.tsx" }),
  ],
});
```

```tsx tab="src/components/mdx.tsx"
import defaultMdxComponents from "fumadocs-ui/mdx";
import type { MDXComponents } from "mdx/types";

export default { ...defaultMdxComponents } satisfies MDXComponents;
```

Import the page and meta schemas from `fumapress/schema`:

```tsx
// [!code --]
import { pageSchema, metaSchema } from "fumapress/adapters/mdx/schema";
// [!code ++]
import { pageSchema, metaSchema } from "fumapress/schema";
```

### Layouts

| Before                       | After                                                                                     |
| ---------------------------- | ----------------------------------------------------------------------------------------- |
| `.layouts({ root })`         | `ui.renderRoot`                                                                           |
| `.layouts({ page })`         | `ui.renderPage`                                                                           |
| `.layouts({ notFound })`     | your own `src/pages/404.tsx` (see [File-based Routing](/docs/routing#file-based-routing)) |
| `.layouts({ defaultProps })` | `ui.baseOptions`                                                                          |
| `renderPage`                 | `ui.renderPage`                                                                           |
| `renderRoot`                 | `ui.renderRoot`                                                                           |
| `renderNotFound`             | `src/pages/404.tsx`                                                                       |
| `defaultLayoutProps`         | `ui.baseOptions`                                                                          |

`ui.baseOptions` can be a plain object or a function when you need `lang` and the site context.

See [Render Page](/docs/layouts#render-page) and [Base Options](/docs/layouts#base-options).

### Translations

The `translations` option and `fumapress/i18n` are refactored. Pass `i18n` to `createPress()`, and move translations under `ui`. Drop the `.extend()` calls for UI, Fumapress and plugin strings (they are added automatically).

```tsx title="press.config.tsx"
// [!code --:6]
import { fumapressTranslations } from "fumapress/i18n";
import { uiTranslations } from "fumadocs-ui/i18n";

const translations = i18n
  .translations()
  .extend(uiTranslations())
  .extend(fumapressTranslations())
  .preset("zh", zhTW());

export default defineConfig({ content, translations });
// [!code ++:5]
export const app = createPress(content, { i18n }).plugins(/* ... */);

export default app.config({
  ui: { translations: i18n.translations().preset("zh", zhTW()) },
});
```

### Preset

`preset: false` is refactored to `preset: []`. To drop a single entry, filter `recommendedPreset()` by `provides`:

```tsx title="press.config.tsx"
import { recommendedPreset } from "fumapress";

createPress(/* ... */).config({
  // [!code --]
  preset: false,
  // [!code ++]
  preset: recommendedPreset().filter((entry) => entry.provides !== "rss"),
});
```

See [Preset](/docs/config#preset) and [Capabilities](/docs/plugins#capabilities).

### Head Tags

`meta` JSX is removed. Use the keyed `head` option instead.

```tsx title="press.config.tsx"
// [!code --:8]
meta: {
  root() {
    return <link rel="icon" href="/favicon.ico" type="image/x-icon" />;
  },
  page(page) {
    return <>{/* page-level meta tags */}</>;
  },
},
// [!code ++:4]
head: [
  { tag: "link", attrs: { rel: "icon", href: "/favicon.ico" } },
],
```

## Layouts

The layout factories of `fumapress/layouts/*` (`createDocsLayoutPage`, `createNotebookLayoutPage`, `createGlassLayoutPage`, `createHomeLayout`, etc.) are refactored. Use Fumadocs UI layouts directly in `ui.renderPage`.

```tsx title="Before"
import { createDocsLayoutPage } from "fumapress/layouts/docs";

const DocsLayout = createDocsLayoutPage<typeof config.$context>({
  treeRoot: "docs",
});

const config = defineConfig({
  renderPage: (props) => <DocsLayout {...props} />,
});
```

```tsx title="After: src/ui/layout.tsx"
import { selectTreeRoot, type RenderPageProps } from "fumapress";
import { DocsLayout } from "fumadocs-ui/layouts/docs";
import { DocsBody, DocsPage, DocsTitle, DocsDescription } from "fumadocs-ui/layouts/docs/page";
import type { app } from "../press.config";

export function renderPage(props: RenderPageProps<typeof app>) {
  const { renderDefault } = props;
  switch (props.type) {
    case "docs":
      return (
        <DocsLayout {...props.baseOptions} tree={selectTreeRoot(props.tree, "docs")}>
          <DocsPage toc={props.pageData.toc} full={props.pageData.full}>
            <DocsTitle>{props.pageData.title}</DocsTitle>
            <DocsDescription>{props.pageData.description}</DocsDescription>
            <DocsBody>{props.body}</DocsBody>
          </DocsPage>
        </DocsLayout>
      );
    default:
      return renderDefault();
  }
}
```

| Before                                           | After                                                                        |
| ------------------------------------------------ | ---------------------------------------------------------------------------- |
| `render().pageProps` / `render().layoutProps`    | props on `DocsPage` / `DocsLayout`                                           |
| `treeRoot: "docs"`                               | `selectTreeRoot(tree, "docs")`                                               |
| interceptors (`renderPage`, `renderPageActions`) | JSX in `renderPage`                                                          |
| `renderPageActions`                              | `props.actions` (typed by installed plugins)                                 |
| `inherit.layoutProps: false`                     | do not spread `baseOptions`                                                  |
| `createLayoutSwitch`                             | `switch (props.type)`                                                        |
| `createHomeLayout()` export in routes            | `HomeLayout` from `fumadocs-ui/layouts/home` with `getBaseOptions({ lang })` |

Own page layouts:

```tsx title="src/pages/_layout.tsx"
import type { ReactNode } from "react";
import { HomeLayout } from "fumadocs-ui/layouts/home";
import { getPressContext, type WakuRouteProps } from "fumapress";
import type { app } from "../../press.config";

export default async function Layout({
  lang,
  children,
}: WakuRouteProps<typeof app> & { children: ReactNode }) {
  const ctx = getPressContext<typeof app>();
  return <HomeLayout {...await ctx.getBaseOptions({ lang })}>{children}</HomeLayout>;
}
```

## Routes

| Before                             | After                                         |
| ---------------------------------- | --------------------------------------------- |
| `RouteConfig`                      | `WakuRouteConfig`                             |

## Search

A custom search dialog moves to `ui.providerProps.search.SearchDialog`. It receives the search plugin's options as props.

```tsx title="press.config.tsx"
// [!code --:6]
import { createRootLayout } from "fumapress/layouts/root";

const Root = createRootLayout({
  providerProps: { search: { SearchDialog } },
});
defineConfig({ renderRoot: (props) => <Root {...props} /> });
// [!code ++:3]
createPress(/* ... */).config({
  ui: { providerProps: { search: { SearchDialog } } },
});
```

See [Custom Dialog](/docs/search#custom-dialog).

## Plugins

### Blog

`fumapress/plugins/blog` is refactored into `@fumapress/blog`.

```tsx
// [!code --:2]
import { blogPlugin } from "fumapress/plugins/blog";
blogPlugin({ isBlog: (page) => page.type === "blog" });
// [!code ++:2]
import { blogPlugin } from "@fumapress/blog";
blogPlugin({ source: "blog" });
```

`source` names a key of the content source. A site whose `isBlog` selects posts out of one source, by path or frontmatter, splits its content into one source per key. The same goes for `isChangelog` of [Tegami](#tegami-changelog).

```tsx title="press.config.tsx"
export const app = createPress({
  docs: docs.toFumadocsSource(),
  blog: blog.toFumadocsSource({ baseDir: "blog" }),
}).plugins(blogPlugin({ source: "blog" }));
```

`layouts` of the blog plugin are refactored into `renderPage` cases. The types are `blog`, `blog.index`, `blog.tags` and `blog.tag`.

```tsx title="src/ui/layout.tsx"
switch (props.type) {
  case "blog":
    return (
      <HomeLayout {...props.baseOptions}>
        <BlogPostView post={props.post} newer={props.newer} older={props.older}>
          {props.body}
        </BlogPostView>
      </HomeLayout>
    );
  case "blog.index":
  case "blog.tags":
  case "blog.tag":
    return <HomeLayout {...props.baseOptions}>{props.children}</HomeLayout>;
  default:
    return renderDefault();
}
```

`getBlogPosts` moves to `@fumapress/blog`. Posts come resolved with `authors`, `tags` (with `.url`), `image` and `date`.

```tsx
// [!code --:3]
import { getBlogPosts, getBlogAuthors, tagSlug } from "fumapress/plugins/blog";
const posts = await getBlogPosts(ctx, page.locale);
const authors = await getBlogAuthors(ctx, page);
// [!code ++:2]
import { getBlogPosts } from "@fumapress/blog";
const posts = await getBlogPosts(getPressContext<typeof app>(), { lang });
```

Blog schemas move to `@fumapress/blog/schema`. Import `@fumapress/blog/css/preset.css` in `src/app.css`.

### Tegami (Changelog)

`isChangelog` is refactored to `source`. `layouts` are refactored into the `changelog.index` case of `renderPage`.

### Image

`imagePlugin` is refactored into named functions:

| Before                                                     | After               |
| ---------------------------------------------------------- | ------------------- |
| `imagePlugin()` from `fumapress/plugins/image/vercel`      | `vercelImage()`     |
| `imagePlugin()` from `fumapress/plugins/image/cloudflare`  | `cloudflareImage()` |
| `imagePlugin()` from `fumapress/plugins/image/self-hosted` | `selfHostedImage()` |

Options are unchanged.

### Takumi

`basePath` is renamed to `path`. `generate` is renamed to `getImage`.

### OpenAPI and AsyncAPI

The import paths are refactored. Options are unchanged.

```tsx
// [!code --:2]
import { openapiPlugin } from "fumapress/plugins/openapi";
import { asyncapiPlugin } from "fumapress/plugins/asyncapi";
// [!code ++:2]
import openapiPlugin from "fumadocs-openapi/press";
import asyncapiPlugin from "@fumadocs/asyncapi/press";
```

### Notion, Sanity, Obsidian, GraphQL

`@fumapress/notion`, `@fumapress/sanity`, `@fumapress/obsidian` and `@fumapress/graphql` are removed. Use the Fumadocs `/press` plugins: `notionPlugin({ notion, ...options })` of `@fumadocs/notion/press`, `sanityPlugin({ components })` of `@fumadocs/sanity/press`, `obsidianPlugin({ vault, components })` of `fumadocs-obsidian/press` and `graphqlPlugin({ server })` of `@fumadocs/graphql/press`.

To replace the Notion renderer, override `getPageBody` of the plugin object: `{ ...notionPlugin({ notion }), getPageBody }`.

### Feedback

Drop `"use server"` from the action. A plain function becomes the `/api/feedback/page` route. A `'use client'` function runs in the browser, which works on static sites. Place `footer.feedback` in custom pages.

### AI

The model option accepts a string ID for the [AI Gateway](https://fumadocs.dev/docs/ui/ai). In custom pages, render `actions.ai` to show the chat trigger.

## Plugin Authors

The plugin contract is refactored from `PressPlugin` to `Plugin` (from `fumapress`, or `@fumapress/core` for packages). Waku-specific hooks move under `waku` (typed as `WakuPlugin`).

| Before                            | After                                                                                                               |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| `PressPlugin<C>`                  | `Plugin<C>` / `WakuPlugin<C>`                                                                                       |
| `createPages(fns)`                | `routes({ createView })` / `waku.createPages(fns)`                                                                  |
| `configureRoutes` + `route.meta`  | `deriveRoutes(fns, { lang, routes })` + `head({ route })`                                                           |
| `createMiddlewares()`             | `middleware(request, next)` / `waku.honoMiddleware()`                                                               |
| `unstable_onServerEntry(entry)`   | `waku.unstable_serverEntry(entry)`                                                                                  |
| `renderPage` hook                 | `getPageView(page, body)`                                                                                           |
| `createApiIsomorphic` / routes    | `routes({ createApi })`, set `render: "static"` for files generated at build time                                   |
| `enforce`                         | list order                                                                                                          |
| `preinit`                         | `provides` (see [Capabilities](/docs/plugins#capabilities))                                                         |
| `this.data[...]` / transformers   | `slots()` / `transformPage()`                                                                                       |
| `translationsConfig.extend(x())`  | `translations: x()`                                                                                                 |
| `AppContext`                      | `Context` (plugins) / `PressContext<typeof app>` (sites)                                                            |
| adapter keys `core:get-body` etc. | `getPageBody` / `getPageToc` / `getPageText` / `getPageStructuredData` / `getPageCreatedAt` / `getPageLastModified` |

See [Writing Plugins](/docs/plugins/authoring).

## From `@fumadocs/astro` 0.1

Install `@fumapress/astro` and `@fumapress/core`, then:

| Before                                                                        | After                                                                                  |
| ----------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| `fumadocs({ layout, page })`                                                  | `press()` plus `ui.renderPage` / `ui.baseOptions` / `ui.providerProps` in press.config |
| `src/fumadocs.config.ts`                                                      | `press.config.tsx` at the project root, `createPress` from `@fumapress/astro/config`   |
| `source: loader(...)`                                                         | `createPress(toFumadocsSource(...))`                                                   |
| `title`                                                                       | `site.name`                                                                            |
| `plugins/openapi`, `asyncapi`, `graphql`, `notion`, `sanity`                  | the `/press` default export of the integration, like `fumadocs-openapi/press`          |
| `plugins/takumi`, `llms.txt`, `flexsearch`, `orama-search`, `link-validation` | the [recommended preset](/docs/config#preset), or `@fumapress/astro/plugins/*`         |
| `plugins/git`                                                                 | `site.git`, and the `lastModified` collection option                                   |
| `plugins/mcp`                                                                 | `mcpPlugin()` of [`@fumapress/ai`](/docs/plugins/mcp)                                  |
| `baseOptions()` of the layout module                                          | `ui.baseOptions`                                                                       |
| the `head` component                                                          | `head` tags                                                                            |
| `useSearch` / `SearchDialog`                                                  | `ui.providerProps.search`                                                              |
| `src/styles/global.css`, the `css` option                                     | `src/app.css`                                                                          |
| `@fumadocs/astro/components/*`                                                | `@fumapress/astro/components/*`                                                        |

URLs change too:

- Pages follow the content source. Add `baseDir: "docs"` to keep them under `/docs`. See [Content](/docs/astro/content#collections).
- Open Graph images move from `/og/<page>/image.webp` to `<page>.webp`.
- The default search is FlexSearch instead of Orama. Add `oramaSearchPlugin()` to keep Orama.

See [Astro](/docs/astro).
