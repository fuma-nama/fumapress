<section id="intro">

Your site starts with a set of default plugins. Add more with `.plugins()`:

```tsx title="press.config.tsx"
import { blogPlugin } from "@fumapress/blog";

export default createPress(content).plugins(blogPlugin({ source: "blog" }));
```

</section>

<section id="replace">

### Replacing a Default Plugin

Add `rssPlugin()` to pass it options. It replaces the default RSS plugin, because both provide `rss`. A site can only have one plugin per `provides` value.

<section id="rest">

## Conditional Plugins and Plugin Order

Falsy values are skipped, so a plugin can be conditional:

```tsx title="press.config.tsx"
const blog = process.env.ENABLE_BLOG && blogPlugin({ source: "blog" });

createPress(content).plugins(blog);
```

The order matters in two places. Middleware is nested in list order, so your first plugin wraps the others. Navbar links also use the list order, after your `ui.baseOptions` links.

</section>
