<section id="intro">

Turn a content source into a blog. Each post gets a page, like `/blog/hello-world`, with an index at `/blog` and tag pages at `/blog/tags`.

</section>

<section id="install">

```npm
npm i @fumapress/blog
```

</section>


```mdx title="content/blog/hello-world.mdx"
---
title: My Blog Post

tags: [my-tag]
authors: [fuma]
```

Posts are ordered by `date`. Each tag gets a page, and `image` shows on post cards.

### Authors

The keys of `authors` are the IDs in the frontmatter. An ID that isn't registered shows as the plain ID.

```tsx title="press.config.tsx"
blogPlugin({
  source: "blog",
  authors: {
    fuma: {
      name: "Fuma Nama",
      title: "Maintainer",
      url: "https://fuma-nama.dev",
      image: "https://github.com/fuma-nama.png",
    },
  },
});
```

### Other Content Sources

Posts can come from any content source, like Notion. The date comes from the `getPageCreatedAt` hook of its plugin. These options read the other fields when they aren't in the frontmatter:

```tsx title="press.config.tsx"
blogPlugin({
  source: "blog",
  getTags: (page) => page.data.tags,
  getAuthors: (page) => page.data.authors,
  getImage: (page) => page.data.image,
});
```

To use multiple sources as posts, pass their keys:

```tsx title="press.config.tsx"
blogPlugin({
  source: ["blog", "news"],
  getTags: (page) => page.data.tags ?? [page.type],
});
```

### URLs

Set a path to move a page, or `false` to remove it:

```tsx title="press.config.tsx"
blogPlugin({
  source: "blog",
  paths: {
    index: "/news",
    tags: false,
  },
});
```

### Custom UI

In [`renderPage`](../layouts.mdx#plugin-pages), a post has the type of its source key, like `blog`. The other pages are `blog.index`, `blog.tags` and `blog.tag`. This example replaces the index, and renders the built-in post in another layout:

```tsx title="press.config.tsx"
import { BlogPostView } from "@fumapress/blog";
import { HomeLayout } from "fumadocs-ui/layouts/home";

renderPage(props) {
  const { renderDefault } = props;
  // the Home Layout takes these props, the others are for docs layouts
  const { nav, links, githubUrl, i18n, themeSwitch, searchToggle } = props.layoutProps;
  const home = { nav, links, githubUrl, i18n, themeSwitch, searchToggle };
  switch (props.type) {
    case "blog.index":
      return (
        <HomeLayout {...home}>
          <ul>
            {props.posts.map((post) => (
              <li key={post.page.url}>{post.page.data.title}</li>
            ))}
          </ul>
        </HomeLayout>
      );
    case "blog":
      return (
        <HomeLayout {...home}>
          <BlogPostView post={props.post} newer={props.newer} older={props.older}>
            {props.body}
          </BlogPostView>
        </HomeLayout>
      );
    default:
      return renderDefault();
  }
},
```

`@fumapress/blog` also exports `BlogIndexView`, `BlogTagsView` and `BlogTagView`.
