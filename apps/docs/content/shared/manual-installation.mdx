Fumapress uses the [Base UI](https://base-ui.com) build of Fumadocs UI by default. To use the [Radix UI build](https://fumadocs.dev/docs/ui/component-library), install `fumadocs-ui` without the alias:

```npm
npm i fumadocs-ui
```

If you installed `@base-ui/react`, you can remove it now.

<Callout>The Spacious Layout needs Base UI.</Callout>
