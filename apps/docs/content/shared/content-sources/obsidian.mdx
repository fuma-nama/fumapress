## Setup

### Install the Package [step]

```npm
npm i fumadocs-obsidian
```

### Add the Styles [step]

Add this after the imports in your stylesheet:

```css title="src/app.css"
@import "fumadocs-obsidian/css/preset.css";
```

### Create the Source [step]

```tsx title="press.config.tsx"
import { obsidian } from "fumadocs-obsidian";
import obsidianPlugin from "fumadocs-obsidian/press";

const vault = obsidian({
  dir: "public/vault",
  url: (file) => `/vault/${file}`,
});

const plugin = obsidianPlugin({ vault }); // [!code highlight]

export default createPress(vault.dynamicSource()).plugins(plugin);
```

## Components

Pass the Fumadocs UI defaults along with your own components, since `components` replaces the defaults:

```tsx title="press.config.tsx"
import defaultMdxComponents from "fumadocs-ui/mdx";

obsidianPlugin({
  vault,
  components: {
    ...defaultMdxComponents,
    img: (props) => <img {...props} className="rounded-xl" />,
  },
});
```
