<section id="write-a-page">

Each file under `content/` is a page. Add one:

```mdx title="content/hello.mdx"
---
title: Hello
description: My second page.
---

## Overview

It is available at `/hello`, and listed in the sidebar.
```

Learn more in [Content](./content.mdx).

</section>
