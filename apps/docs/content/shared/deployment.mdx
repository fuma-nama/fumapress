<section id="routes">

Pages of a static source are prerendered. Pages of a dynamic source, like [Notion](./content-sources/notion.mdx), render on demand, and one site can mix both. Files generated from your content, like `.md` files, the sitemap and Open Graph images, use the same render mode as their pages.

</section>

<section id="server">

- A dynamic source, like [Notion](./content-sources/notion.mdx) and [Sanity](./content-sources/sanity.mdx).
- [AI chat](./plugins/ai.mdx#ai-chat) and [MCP](./plugins/ai.mdx#mcp).
- The [OpenAPI proxy](./plugins/api-docs.mdx#proxy).
- [Feedback](./plugins/feedback.mdx) with actions on the server. Actions in the browser don't need a server.
- [Server-side search](./search.mdx#server-side-search), when you enable it.
- Custom pages and API routes rendered on demand.
- Plugin middleware, like [authentication](./authentication.mdx).

</section>
