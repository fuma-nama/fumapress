<section id="cli-intro">

```bash
npx @fumadocs/cli add banner
npx @fumadocs/cli customize
```

The Fumadocs CLI copies Fumadocs UI into your project, so that you can change its source. `add` copies a component, and `customize` copies a layout. Fumapress styles still apply to the copies.

</section>

<section id="cli-trap">

<Callout title="Features come from plugins">

<section id="swap">

### Use Another Layout

Swap the two imports:

```tsx tab="Docs"
import { DocsLayout } from "fumadocs-ui/layouts/docs";
import { DocsBody, DocsDescription, DocsPage, DocsTitle } from "fumadocs-ui/layouts/docs/page";
```

```tsx tab="Notebook"
import { DocsLayout } from "fumadocs-ui/layouts/notebook";
import { DocsBody, DocsDescription, DocsPage, DocsTitle } from "fumadocs-ui/layouts/notebook/page";
```

```tsx tab="Glass"
import { DocsLayout } from "fumadocs-ui/layouts/glass";
import { DocsBody, DocsDescription, DocsPage, DocsTitle } from "fumadocs-ui/layouts/glass/page";
```

```tsx tab="Spacious"
import { DocsLayout } from "fumadocs-ui/layouts/spacious";
import { DocsBody, DocsDescription, DocsPage, DocsTitle } from "fumadocs-ui/layouts/spacious/page";
```

Glass and Spacious also need their styles. Use `spacious.css` for Spacious.

```css title="src/app.css"
@import "tailwindcss";
/* [!code ++] */
@import "fumadocs-ui/css/generated/glass.css";
@import "fumadocs-ui/css/neutral.css";
```

<Callout>
  Glass and Spacious are client components, so their props can't contain functions, other than the
  slots they support. Their styles go before the theme, so replace a combined stylesheet like
  `default.css` with the separate [theme imports](./configuration.mdx#colors).
</Callout>

### Plugin Pages

Plugin pages, like the blog index, use the Home Layout by default. To restyle them, add a case with `props.children`, the plugin's content without a layout:

```tsx title="press.config.tsx"
import { HomeLayout } from "fumadocs-ui/layouts/home";

renderPage(props) {
  const { renderDefault } = props;
  switch (props.type) {
    case "blog":
    case "blog.index":
    case "blog.tags":
    case "blog.tag":
      return (
        <HomeLayout {...props.baseOptions}>
          <main className="mx-auto max-w-[1400px] px-4 py-6">{props.children}</main>
        </HomeLayout>
      );
    default:
      return renderDefault();
  }
},
```

To replace the content too, use the plugin's props, like in [the blog](./plugins/blog.mdx#custom-ui).
