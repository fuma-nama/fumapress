<section id="why">

Fumapress has no built-in login. You check the session in plugin middleware, which only runs for routes rendered on demand. Prerendered pages and files in `public/` never reach it.

</section>

<section id="check">

`getSession()` stands for your own session check. List this plugin first, so that it wraps the others.

```tsx title="press.config.tsx"
createPress(content).plugins({
  name: "site:auth",
  async middleware(request, next) {
    const session = await getSession(request);
    if (!session) return new Response("Unauthorized", { status: 401 });

    return next();
  },
});
```

Now every page, and every file made from your content, like `/llms.txt`, requires a session.

</section>

<section id="rest">

Do the first step above, then check that the URL starts with the prefix. This covers client navigations and `<page>.md` too.

```tsx title="press.config.tsx"
createPress(content).plugins({
  name: "site:auth",
  async middleware(request, next) {
    const { pathname } = new URL(request.url);
    const session = await getSession(request);

    const isInternal =
      pathname.startsWith(this.withBase("/internal")) || pathname === this.withBase("/internal.md");

    if (isInternal && !session) return new Response("Unauthorized", { status: 401 });
    return next();
  },
});
```

With [internationalization](./internationalization.mdx), the language prefix comes first, like `/zh/internal`.

Other spellings of a path, like `//internal` and `/%69nternal`, redirect to the normal one first, so your check only sees `/internal`.

</section>

### Cover Generated Routes

Plugins serve your pages at other paths, outside the prefix. Check these paths in the same middleware, filter the section out with options of the plugin, or remove the plugin.

## Hide Pages from the Sidebar

Middleware blocks a page, but its link stays in the sidebar. Remove the folder from the page tree, the data behind the sidebar:

```tsx title="press.config.tsx"
createPress(content, {
  loaderOptions: {
    pageTree: {
      transformers: [
        {
          root(node) {
            return {
              ...node,
              children: node.children.filter((item) => item.name !== "Internal"), // [!code highlight]
            };
          },
        },
      ],
    },
  },
});
```

The tree is the same for every reader, so the section is hidden from everyone, signed in or not.
